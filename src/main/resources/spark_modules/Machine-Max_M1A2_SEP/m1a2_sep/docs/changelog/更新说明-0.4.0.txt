M1A2 SEP — MachineMax 内容包 0.4.0

独立车长席、CITV 车长观瞄、独立遥控武器站操作席，以及 170° 后部 M2 水平射界。

安装与使用

使用 Machine-Max_M1A2_SEP-0.4.0.zip 或 Machine-Max_M1A2_SEP 文件夹替换 spark_modules 中的同名旧包，只保留一种安装形式。包 ID 为 m1a2_sep:pack，仅依赖 machine_max:builtin。
重启客户端后重新生成 M1A2 SEP 完整装配体（模板 ID m1a2_sep:m1a2_sep），使七席和新的控制组生效。已生成车辆可能保留原来的座位、控制组和关节实例。
若已启用 MMX_Addon_Languages.zip，配套语言包须与附属包一起更新。无需替换模组 JAR。
0.3.10 工程与安装包备份：backups/0.3.10-before-independent-commander/。

七个席位

驾驶员：车体驾驶入口，控制车辆行驶。
炮手：控制 120 mm 主炮和随炮运动的 M2 副武器，使用 GPS 主炮镜。
车长：入口在左侧 M240B 前方的圆筒观瞄上方，提示“进入车长位”。独立使用 CITV 观察与主炮超控。
遥控武器站操作员：入口在右前武器站枪座上部，提示“进入遥控武器站操作席”。仅控制该武器站 M2。
装填手：保留乘坐席位。
左侧机枪手：操作 M240B，入口在枪座上方外缘。
后部机枪手：操作后部 M2，入口随枪架回转。

车长控制与观瞄

车长默认处于“车长独立观察”组，观察不会带动主炮。按 Tab 切换到“车长超控：主炮／同轴”，主武器键控制 120 mm 主炮，副武器键控制主炮上方 M2；再按 Tab 返回观察。按键以游戏中的实际绑定为准。
V 在普通视角、CITV 与已发现的主炮镜之间切换；Z 调整倍率。CITV 使用模型中 M240B 前方圆筒观瞄的位置，视点置于外壳前上方，采用独立相机；游戏倍率 1–8 倍，水平可全周观察，俯仰 −20°～60°，为昼间观察画面。
CITV 使用模组内置观瞄准心、方位和名称显示。主炮 GPS 绿色分划保持 3–10 倍；测距预留显示 ---- / NO RANGE，没有伪造距离或新增 CRT 组件。
车长与武器站分别拥有座位、入口、观瞄发现和控制预设。车长超控只寻址主炮与副武器火控，不带动 RWS、M240 或后部 M2。
超控沿用现有模组机制：车长 p1 瞄准优先于炮手 p2。模组仍接受炮手开火请求，因此不是禁止炮手开火的独占锁。

后部 M2 射界

水平扇区覆盖右侧、正后方及另一侧后方，共 170°；配置角度 −240°～−70°，跨越 −180°，等价于 120° 经正后方至 −70°。初始角保持 −155°。俯仰保持 −12°～45°。
天线的可见穿模按用户要求忽略。与 RWS、M240 的可见几何完成静态多姿态核对；不扩大到前方硬件密集区。枪体、枪架、炮口与射速均未移动或改变。
大仰角 45° 时后部 M2 枪尾与原模型舱圈存在既有外观相交；本版保留该造型与俯仰范围，不将几何采样称为全部姿态无穿模。
