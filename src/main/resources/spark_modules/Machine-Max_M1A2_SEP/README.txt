0.5.10 附加装甲使用变体

车体与炮塔的附加装甲各是一个零件类型，用 left / right 两个变体区分左右。模板放置六个零件实例；uuid、坐标、碰撞箱、质量、连接点与标签保持原值，registry_key、name 与 variant 指向合并后的类型。合并后的零件与研发条目共用一张中性图标（m1a2_hull_armor.png、m1a2_turret_armor.png）。

制造配方、研发条目和中英文名称各一份，费用与耗时分别为车体 150、炮塔 75。

迁移：零件类型 id 由 m1a2_hull_armor_left / m1a2_hull_armor_right 改为 m1a2_hull_armor，由 m1a2_turret_armor_left / m1a2_turret_armor_right 改为 m1a2_turret_armor。旧装配体与按旧 id 记录的研发进度需要重新生成整车并重新研发；蓝图引用模板，不受影响。模型、贴图与几何未改。

历史版本说明

0.5.9 三档主炮镜与分划

主炮 GPS 采用 3×、6×、12× 三个固定倍率，炮手和车长均可通过原生“视角循环”键切换；本机通常为 V，按实际键位设置为准。炮手进入后依次为 3→6→12，再回普通观察；车长循环中另外保留独立 CITV。原生变倍键只支持基础／最大两个端点，本版三档通过同镜窗、同双稳参数的三个原生 camera 实例实现，因此固定档位内按原生变倍键不会改变倍率。

3×：搜索框、简化中央线段、小圆环和瞄准点。
6×：原有 GPS 阶梯横线、分段竖线、小圆环和瞄准点。
12×：保留中央 GPS 分划，主炮被当前控制组选中时增加 500、1000、1500、2000、2500 米弹道瞄准刻线，位置由原生 weapon.bdc_hold_rad() 随当前主炮弹药及画面 FOV 计算。AP／HE 对应不同落差；没有可用弹道时隐藏刻线，不填假数据。未超控的车长只观察主炮镜时不显示属于武器控制器的弹道刻线。

三档共用右侧车顶 gunner_optic 镜窗。沿用原生 CameraSubsystem.enterView(expectedPoint) 继承切出镜头的世界瞄准点；双轴稳定、俯仰、偏航和回转速度保持原配置。独立运行环境中实际类完成了 162 次切档方向继承与同挂点检查；炮手和车长均按配置顺序发现三档镜头。

本组三档与分划分工是按用户要求制作的游戏适配，不声称与某版战术小队的资产逐像素一致，也不声称实车 GPS 日间光学具有 3/6/12 三档。高倍弹道刻线使用本包 AP/HE 参数的静止平台、海平面、同高目标标准弹道，不是实际目标测距、风偏、运动提前量或自动火控解算；距离栏仍为 ---- / NO RANGE。弹种选择、膛内状态与供弹显示继续使用既有 HUD。

原黄色分划、史实小圆环、大镜口与平滑暗角保留。CITV、武器站、后部 M2、所有武器射速／供弹／弹道参数、装甲、连接器、质量、履带及悬挂配置保持原版。T90A 沿用此前 0.1.16，没有随本次修改。

需要重启客户端并重新生成完整 M1A2 装配体，加载新增的两档 camera 子系统。没有更新模组 JAR，没有新增客户端组件，未启动 Minecraft，尚未实机验收。
备份：backups/0.5.8-before-three-stage-optics/。

历史版本说明

M1A2 SEP — MachineMax 内容包 0.5.7

M1A2 SEP 艾布拉姆斯主战坦克内容包，包含七个席位、M240 常规同轴、炮盾 CSAMM 反狙击 M2、独立车长观瞄及主炮超控、遥控武器站、程序化履带与分区装甲。

安装

将 Machine-Max_M1A2_SEP-0.5.7.zip 或同名文件夹装入 spark_modules，只保留一种安装形式。包 ID m1a2_sep:pack，依赖 machine_max:builtin。配套语言资源包为 MMX_Addon_Languages.zip。
重启客户端并重新生成完整装配体（m1a2_sep:m1a2_sep），使新增的 M240 发射器和供弹器生效。模组 JAR 无需替换。

朝向 HUD

左上角增加车体／炮塔俯视小图，炮管指针固定朝上，车体轮廓使用真实炮塔—车体连接角度反向表示相对方位；下方 L/R 与角度表示相对车体的左／右偏转，并非世界罗盘方位。七个座位的普通视角、GPS 主炮镜、车长 CITV 和武器站观瞄均显示同一个小图；切换武器组不改变它。炮塔与车体断开时隐藏指针和角度，显示 NO LINK。
无需新增客户端组件或更新模组 JAR。重启客户端以加载新的 HUD 资源；已有载具的座位 HUD 如未刷新，可重新生成完整装配体。

舱外机枪弹匣

武器站 M2 与后部 M2 各使用独立 100 发弹箱，打空后自动换弹 8 秒；左侧 M240 使用独立 200 发弹箱，打空后自动换弹 6 秒。未打空时停止射击不会补回余量，换弹期间不能连续供弹；没有新增手动 R 键换弹。HUD 显示实际弹匣余量与换弹状态。常规 M240 同轴和炮盾 CSAMM M2 保留原有供弹。容量与换弹时间是本内容包游戏适配值。

炮手武器切换

主武器键始终控制 120 mm 主炮，副武器键由当前控制组决定。Tab 默认为切换控制组，循环如下：
1. 炮手：主炮＋M240同轴（默认）——主武器键发射主炮，副武器键发射 7.62 mm M240。
2. 炮手：主炮＋反狙击M2——主武器键发射主炮，副武器键发射炮盾上的 12.7 mm CSAMM M2。
3. 炮手：仅主炮——主武器键发射主炮，副武器键无武器输出。
再次 Tab 回到默认组。按键以游戏实际绑定为准。AP/HE 使用“下一个弹种／上一个弹种”按键切换。
主炮、M240 和 CSAMM 使用各自的控制及供弹频道。切组清除旧输入；左下角只显示当前选中机枪的弹药、膛内与供弹状态，切组提示显示当前模式名。主炮 HUD 在炮手三档均可用。

车长控制

车长默认位于基础组“车长：独立观察／备用驾驶”，不发送武器开火信号。Tab 切至“车长超控：主炮＋M240同轴”，再切至“车长超控：主炮＋反狙击M2”，再回到独立观察。
两种超控组使用与炮手相同的主、副武器关系。车长 p1 瞄准优先于炮手 p2；模组仍接受炮手的开火输入，因此超控不是禁止炮手开火的独占锁。
车长三档均保留 W/A/S/D 备用驾驶、常规驾驶按键和 CITV 控制。驾驶员的 p1 行驶输入优先于车长备用频道。
V 切换普通视角、CITV 与已发现的主炮镜；Z 调整倍率。CITV 上部独立水平回转 360°、最高 90°/s，底座固定；游戏观察倍率 3–13 倍，内部俯仰观察 −20°～60°。GPS 主炮镜使用黄色分划和 3–10 倍倍率，测距预留 ---- / NO RANGE。

M240 同轴与反狙击 M2

常规 M240 使用原模型主炮旁的短枪管，随炮盾俯仰；仅新增枪口定位器与隐藏命中标记，原可见枪体和贴图坐标保留。该机枪拥有独立 7.62 mm 供弹器，游戏弹仓 1000 发，射速 750 发/分，基础伤害 10、穿深 8。
炮盾上方 M2 作为 CSAMM 反狙击／反器材副武器，保留射速 550 发/分、基础伤害 24、穿深 16及独立 12.7 mm 供弹器。M240 与 CSAMM 的弹药面板按选中控制组显示。
遥控武器站 M2、舱外后部 M2 与左侧 M240 由各自席位控制，使用各自供弹器。全车共五门机枪，七个席位：驾驶员、炮手、车长、武器站操作员、装填手、左侧机枪手、后部机枪手。

射界与车辆

RWS 实际模型偏航 −137.5°～127.5°，共 265°，俯仰 −20°～55°。后部 M2 偏航 −242.5°～−65°，共 177.5°，初始角 −155°，俯仰 −12°～45°。左侧 M240 偏航 −110°～110°、俯仰 −12°～55°。极端俯仰与邻枪同时回转仍可能出现可见交叠；后部 M2 天线穿模按用户要求忽略。
六个独立 Part：车体与轮组、炮塔与武器、左右车体附甲、左右炮塔附甲。总质量 21,560 kg，18 个车轮、两条程序化履带、硬悬挂。炮管为独立 SubPart，座圈采用 2S38 的普通受击断开方案。
原涂装与橄榄绿喷漆按独立 Part 切换。主炮 AP/HE、五门机枪参数见 weapon-parameters.txt；分区基甲近似值见 armor-parameters.txt。
