2S38 履带节数（2026-11-05）

每侧 88 节。2S38「偏流-ПВО」的战斗舱装在 BMP-3 底盘上，行走部分与 BMP-3 相同：
每侧 6 个负重轮、3 个托带轮、主动轮在后、诱导轮在前，每侧履带板 88 块。

来源：
- 中华网武器大全《BMP-3步兵战车》「技术特点 · 机动性能」：
  「每侧的履带板数量为88块。」
  https://m.junshi.china.com/wuqi/14257.html
  同页「底盘类型：履带式」「轮胎负重轮数量：六对」用于确认底盘构型与轮系。

写在哪儿：
- 节数是具体一环履带的属性（轮组数量、间距不同，节数就不同），因此不进
  fittings/2s38_track.json，而是写进载具数据的每一条履带：
  templates/2s38.json 的 track_links[] 里左右两条各带 "link_count": 88。
  载具从模板 / 蓝图放出时加载端直接采用该值，不再按包络周长反推。
- 最大耐久 = durability_per_link × N = 20 × 88 = 1760；客户端按 88 节铺满包络。
- length_per_link（0.2）与单节模型尺寸不变，仍是主动轮啮合段的标称节距。
