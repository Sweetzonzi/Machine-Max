# 2.7 载具保存与收纳

在拼装好一辆载具后，你可能会希望将它保存起来，以便在需要时重新放出——无论是为了运输车辆跨越长距离、备份一份心爱的设计，还是为了在生存模式中将载具转化为可携带的物品形态。MachineMax 提供了两种不同取向的保存方式：**蓝图保存**和**封装收纳**。前者保留一份结构记录用于日后重新制造，后者将整个载具直接打包成物品随身携带。

## 空白蓝图——记录载具结构

空白蓝图（EmptyBlueprintItem）是最直接的载具保存工具。手持空白蓝图，将准星对准一辆载具上的任意部件右键，系统会打开一个命名界面。你可以在其中输入一个自定义名称，确认后即可完成保存。

保存成功时，空白蓝图会被消耗并转化为一张**载具蓝图物品**（VehicleBlueprintItem），同时一份与该蓝图同名的 JSON 文件会保存到游戏客户端的 `.minecraft/saved_blueprints` 目录下。这个 JSON 文件记录了载具的完整拓扑结构——包括所有零件的类型、变体、连接关系以及涂装状态，格式与内容包中的装配体模板一致，可以直接用于内容包制作（详见 [5.7 模板、蓝图与装配体](../5-内容包制作教程/5.7-模板、蓝图与装配体.md)）。

需要注意的是，空白蓝图只是记录载具的结构，**不会将载具从世界中移除**。保存操作完成后，原有的载具仍然完好地留在原地——你相当于拿到了一份它的"设计图"，未来可以拿着这份设计图在其他地方重新制造一辆结构完全相同的载具。

## 载具蓝图——预览与再生

手持**载具蓝图物品**时，你会在视野中看到一个半透明的立方体轮廓，它标出了载具放置时大致占据的空间范围。轮廓的颜色用于指示放置位置的合法性：绿色表示当前位置没有障碍物阻挡，可以放置；红色则表示目标位置存在碰撞，需要重新选择位置。

按下右键后，蓝图会根据存储的结构数据在世界中生成一整辆载具。与成品部件物品直接放置不同，蓝图生成的载具**组装进度全部为零**——所有零件的结构和连接关系已经就位，但它们的功能尚未激活，耐久度也处于最低状态。你需要手持焊枪逐一投入材料完成组装，才能让这辆载具正常运转。这个过程和在生存模式中使用制造蓝图物品拼装载具后的处理方式是一致的（关于焊枪的组装流程，请参考 [2.3 组装修复](2.3-组装修复.md)）。

载具蓝图物品也支持 3D 模型预览。GUI 中会显示该载具的立体缩略模型，方便你在不拿在手中的情况下快速辨认蓝图的内容。如果蓝图来自内容包（而非玩家自行保存的），还会附带说明文字。

## 末影GK树脂——封装为装配体

如果你需要将一辆载具从世界中移除并直接打包成可携带的物品形态，可以使用**末影GK树脂**（EnderGkResinItem）。手持末影树脂，对准载具上的任意部件右键，整辆载具的所有结构数据会被保存到一个**装配体物品**（AssemblyItem）中，同时原有的载具会从世界中消失，末影GK树脂被消耗。

封装后得到的装配体物品携带了载具的完整数据。右键地面即可将装配体中存储的所有部件以完整载具的形态重新放置出来——与蓝图不同，装配体放置出来的零件**全部处于完全组装状态**，无需再经过焊枪投入材料的过程。

末影树脂是一次性消耗品，封装一次就会消失。如果你持有末影树脂但对准的不是载具部件，右键不会有任何效果，树脂也不会被消耗。

## 蓝图与装配体的区别

蓝图保存和封装收纳虽然都能将载具结构保存到物品中，但二者的使用定位有所不同。

蓝图记录的是**设计**。保存后载具仍留在原地，你拿到的是一份可以复用的设计图。放出的载具需要重新组装——这适合你已经在生存模式中完成了研发和制造，掌握了所有必要材料，想在其他地方复制同一设计的情况。蓝图的另一个优势是附带的 JSON 文件可以直接用于内容包制作，同时也为未来从研发台直接导出已保存的设计留下了扩展空间。

封装收纳处理的是**实物**。载具被直接打包成物品带走，放出来就是组装完成的成品。这适合需要快速移动载具的场景——例如你在某个地方造好了一辆车，想把它带到远处的基地去，就可以用末影GK树脂把它打包带走，到了目的地再原样放出来。

| <br />  | 蓝图保存                   | 封装收纳       |
| ------- | ---------------------- | ---------- |
| 使用工具    | 空白蓝图                   | 末影树脂       |
| 工具消耗    | 空白蓝图变为载具蓝图             | 消耗         |
| 原载具     | 保留在世界中                 | 从世界中移除     |
| 产出物品    | 载具蓝图物品                 | 装配体物品      |
| 放出状态    | 组装进度为 0                | 完全组装       |
| JSON 保存 | 保存至 `saved_blueprints` | 不单独保存 JSON |
