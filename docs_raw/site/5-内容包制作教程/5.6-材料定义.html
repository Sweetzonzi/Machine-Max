    5.6 材料定义¶

    材料定义 JSON 放置在 materials/ 模块目录下，用于描述一个命中箱材料的基础物理属性。它不像零件定义那样直接决定模型、连接点或子系统，而是作为命中箱的“共用基线”，统一控制摩擦、滑移、弹性、方块破坏能力、装甲抗穿水平，以及受到伤害时如何把原始数值转换为穿深、冲击和最终伤害。

    如果把命中箱理解为“几何形状 + 厚度 + 材料”的组合，那么几何形状决定碰撞体在哪里，厚度决定这一块有多厚，而材料决定“这块东西是什么做的”。这一点和第四章中的 4.3 装甲与穿甲、4.4 伤害系统 是直接对应的：rha、angle_effect、penetration_modifiers 会影响能不能打穿；impact_modifiers、damage_modifiers、un_penetrate_damage_factor 会影响打上去以后具体怎么坏。

    阅读本章前，建议先完成：

    • 5.3 零件定义 中关于 hit_boxes 的部分；
    • 4.3 装甲与穿甲；
    • 4.4 伤害系统。

    文件位置¶

    材料定义 JSON 放在内容包对应的命名空间目录下：

    spark_modules/
└── my_pack/
    └── my_mod/
        └── materials/
            ├── structural_steel.json
            ├── glass.json
            ├── normal_tire.json
            └── ceramic_armor.json

    每个文件名（不含扩展名）即为该材料的内部 ID。模组加载时，以 命名空间:文件名 的格式注册材料，例如 my_mod:structural_steel。之后在命中箱定义中，通过 material 字段引用：

    "HullHitBox": {
  "type": "box",
  "material": "my_mod:structural_steel",
  "thickness": 6.0
}

    与 parts/、subsystems/ 等模块相同，materials/ 下的 JSON 文件可以任意嵌套子文件夹来组织，但注册名仍然只取文件名本身，不包含路径。

    材料与命中箱的关系¶

    材料本身并不直接出现在世界里，它只会在命中箱引用后生效。对命中箱来说，材料定义主要承担三类职责：

    1. 决定碰撞和接地表现，例如摩擦、滚动阻力、滑移曲线和弹性。
    2. 决定装甲与穿深相关行为，例如 rha、角度效应和未击穿残余伤害。
    3. 决定伤害如何被映射与修正，例如冲击修正、穿深修正和最终耐久伤害修正。

    在第四章中，一个命中部位的基础装甲可近似写成

    $$ A_{\text{base}} = t \cdot \text{RHA} $$

    其中 $t$ 是命中箱定义中的 thickness，RHA 则来自材料定义中的 rha。也就是说，材料定义提供的是“每单位厚度有多抗穿”，而不是整块装甲的最终强度。真正的防护水平仍然要和命中箱厚度一起看。

    同样地，4.4 中提到的三类伤害入口

    $$ I = f_{\text{impact}}(D), \qquad P = f_{\text{pen}}(D), \qquad D_{\text{final}} = f_{\text{damage}}(D) $$

    其中的 $f_{\text{impact}}$、$f_{\text{pen}}$ 和 $f_{\text{damage}}$，正是由材料中的 impact_modifiers、penetration_modifiers 和 damage_modifiers 提供。换句话说，材料不是在“加一点小修正”，而是在参与伤害系统的主干流程。

    顶层字段¶

    材料定义 JSON 的顶层字段如下：

    字段 类型 必需 默认值 说明
    $schema 字符串 否 — JSON Schema 引用路径，供编辑器提示和校验
    friction 三维向量 否 [0.5, 0.5, 0.5] 摩擦系数向量，主要用于轮胎和地形接触
    slip_adaptation 浮点数 否 0.5 滑移适应系数，控制湿滑和打滑时抓地衰减有多严重
    slip_curve 对象 否 默认滑移曲线 轮胎纵向与侧向滑移曲线
    rolling_friction 浮点数 否 0.2 滚动摩擦系数
    spinning_friction 浮点数 否 0.0 旋转摩擦系数
    restitution 浮点数 否 0.1 恢复系数（弹性）
    block_damage_factor 浮点数 否 1.0 方块破坏系数
    rha 浮点数 否 1.0 相对 RHA 抗穿系数
    angle_effect 布尔值 否 true 是否启用角度效应
    impact_modifiers 修改器数组 否 默认规则 把输入伤害映射为连接点冲击
    penetration_modifiers 修改器数组 否 默认规则 把输入伤害映射为穿深
    damage_modifiers 修改器数组 否 默认规则 把输入伤害映射为最终部件伤害
    un_penetrate_damage_factor 浮点数 否 0.0 未击穿残余伤害指数
    sounds 对象 否 默认金属音效 材料被命中时的音效配置

    从用途上看，这些字段可以分成三组来理解：

    • 接地与碰撞：friction、slip_adaptation、slip_curve、rolling_friction、spinning_friction、restitution
    • 装甲与穿深：rha、angle_effect、penetration_modifiers、un_penetrate_damage_factor
    • 伤害与破坏：impact_modifiers、damage_modifiers、block_damage_factor、sounds

    摩擦与接地字段¶

    friction¶

    friction 是一个三维向量，格式为：

    "friction": [x, y, z]

    当前实现里，x 主要对应侧向摩擦，y 主要对应前向摩擦，z 没有明确实际效果，通常保持默认或与前两者接近即可。对于轮胎材料，这个字段直接参与了 4.1 中讲到的各向异性轮胎摩擦；对于普通车体材料，则更多表现为一般接触时的摩擦强弱。

    因此：

    • 希望轮胎直线抓地更强，可以优先提高前向分量；
    • 希望轮胎转向支撑更强，可以提高侧向分量；
    • 希望车体、滑撬、底板更容易滑移，则应适当降低对应分量。

    slip_adaptation¶

    slip_adaptation 取值范围为 0~1，用于减弱湿滑和滑移对抓地力的削弱。在 4.1 中我们已经把它近似写成

    $$ \text{effective_slip}=\text{slip}\cdot (1-\text{slip_adaptation}) $$

    因此这个值越高，同一块湿滑地面给轮胎带来的附着损失就越小。越野胎和全地形胎通常应当给出更高的 slip_adaptation，而一些极端偏公路、高极限但怕湿地的轮胎，则可以把它压低。

    slip_curve¶

    slip_curve 只在轮胎类材料上尤其重要，用于控制纵向滑移率和侧向滑移角变化时，摩擦缩放如何变化。它包含两组子对象：

    • longitudinal
    • lateral

    longitudinal¶

    字段 类型 默认值 说明
    peak_slip_ratio 浮点数 0.20 达到峰值摩擦的纵向滑移率
    base_scale 浮点数 1.0 滑移率为 0 时的摩擦缩放
    peak_scale 浮点数 1.4 峰值滑移率处的摩擦缩放
    kinetic_scale 浮点数 0.9 高滑移状态下的动摩擦平台

    lateral¶

    字段 类型 默认值 说明
    peak_angle_deg 浮点数 12.0 峰值侧偏角（度）
    kinetic_angle_deg 浮点数 90.0 进入高侧偏角动摩擦平台的角度
    base_scale 浮点数 1.0 侧偏角为 0 时的摩擦缩放
    peak_scale 浮点数 1.2 峰值侧偏角处的摩擦缩放
    kinetic_scale 浮点数 0.7 高侧偏角下的动摩擦平台

    如果你希望一条轮胎更适合稳定抓地，应当让 peak_scale 较高、kinetic_scale 不至于掉得太多；如果希望它更容易进入漂移，则可以让峰值出现得更早，并让高侧偏角下的平台更低。

    rolling_friction 与 spinning_friction¶

    rolling_friction 控制正常滚动时的阻力，直接影响滑行距离、巡航掉速和通过松软地面的吃力程度；spinning_friction 则更多影响绕接触法线方向扭动时的阻力，例如低速转向、原地扭身和轮胎拖拽。

    它们不直接决定“能不能抓住地”，而是更多决定“抓住之后阻力有多大”。因此，公路胎、越野胎、金属履带、滑板、木质雪橇这类材料，就算基础摩擦差不多，这两个值也可以显著拉开操控手感。

    restitution¶

    restitution 是恢复系数，范围 0~1。在碰撞章节中我们已经见过，它会直接参与碰撞能量与反弹计算。值越高，碰撞越偏向反弹；值越低，越偏向吸收能量。

    对材料调校来说：

    • 玻璃、硬橡胶、轮胎、冰面可以适当提高；
    • 装甲钢、木材、纸、软塑料通常更适合较低值；
    • 若某种材料碰撞后老是弹得过头，优先检查这个字段。

    装甲与穿甲字段¶

    rha¶

    rha 是材料相对轧制均质装甲的抗穿系数。在 4.3 中，命中部位的基础装甲已经写成

    $$ A_{\text{base}} = t \cdot \text{RHA} $$

    其中 RHA 就来自这里的 rha。默认值是 1.0，可以理解为“同厚度下，相当于标准 RHA 的抗穿水平”。

    例如：

    • rha = 0.5：同样厚度下只有一半的等效抗穿
    • rha = 1.0：标准基准
    • rha = 1.5：同样厚度下达到 1.5 倍等效抗穿

    需要特别注意的是，rha 不是最终装甲值，它必须和命中箱的 thickness 一起看。调 rha 是在改材料质量，调 thickness 是在改几何厚度，两者职责不同。

    angle_effect¶

    angle_effect 决定该材料是否启用入射角导致的等效厚度变化。若启用，则等效装甲近似为

    $$ A_{\text{eq}}=\frac{A_{\text{base}}}{|\cos\theta|} $$

    这在 4.3 里已经详细讲过。对内容包作者来说，这个开关非常重要：

    • 传统装甲板、斜面钢板通常应当保持 true
    • 玻璃、布料、某些非典型防护层可以考虑设为 false

    如果你发现某种材料做成斜面后防护提升不符合预期，首先就应检查这里。

    penetration_modifiers¶

    penetration_modifiers 用于把输入伤害映射成最终参与击穿判定的穿深。它正对应 4.3 中的

    $$ P = f_{\text{pen}}(D) $$

    默认规则会让大多数不具备穿甲标签的伤害，在换算穿深时乘上一个较低系数。这样做的目的是避免原版普通伤害过于轻易地打穿重型命中箱。

    这组修正器最适合用来表达：

    • 某种材料特别怕爆炸冲击，但不怕普通小口径
    • 某种材料对高能穿甲弹和钝击的抗性差异很大
    • 某类命中来源应当几乎没有有效穿深

    un_penetrate_damage_factor¶

    这个字段控制“没打穿时还有没有残余伤害”。在 4.3 中，未击穿残余伤害已经近似写成

    $$ D_{\text{unpen}} = D_{\text{base}} \left(\frac{P}{A_{\text{eq}}}\right)^k $$

    其中 $k$ 就是 un_penetrate_damage_factor。

    当它为 0.0 时，未击穿通常就没有额外残余伤害；当它大于 0 时，系统允许“差一点打穿”的攻击仍然对内部造成一定损伤。玻璃、脆性结构、冲击敏感设备和薄板后挂设备，都很适合利用这个字段来表现“没穿也会震坏”。

    伤害与破坏字段¶

    impact_modifiers¶

    impact_modifiers 用于把输入伤害映射为连接点冲击，它对应 4.4 中的

    $$ I = f_{\text{impact}}(D) $$

    这组修正器不会直接决定部件掉多少耐久，而是决定这次受击对连接点结构完整性有多大影响。因此它特别适合用来区分：

    • “本体不一定很脆，但很容易把外挂件震掉”
    • “本体容易掉血，但结构连接很稳”
    • “对撞击特别敏感的脆性部件”

    如果你发现某个材料总是“本体还没坏，东西先掉了一地”，优先检查的就应该是这里，而不是只盯着 damage_modifiers。

    damage_modifiers¶

    damage_modifiers 对应最终写入部件耐久的伤害，也就是 4.4 中的

    $$ D_{\text{final}} = f_{\text{damage}}(D) $$

    它决定的是“这次攻击最后到底扣多少血”。默认规则里已经包含了一些很常见的防帧伤处理，例如减弱浆果丛、史莱姆等会高频触发的小额伤害。

    最常见的用途包括：

    • 忽略过小的碰撞伤害
    • 显著减弱某类环境伤害
    • 让某种材料对特定伤害类型特别脆或特别硬

    如果你做的是玻璃、纸板、橡胶护罩、木箱之类的材料，这一组字段往往会比 rha 更早决定它们的实际表现。

    block_damage_factor¶

    block_damage_factor 主要作用在 4.5 讨论过的方块碰撞与破坏流程中。它不是在改车辆对自身掉血，而是在改“撞方块时有多擅长把能量施加到方块那一侧”。

    因此：

    • 撞角、推土板、金属履带、工程机具前端可以适当提高；
    • 轮胎、玻璃、脆性外壳应当降低；
    • 设为 0 则等于完全不适合破障

    命中音效字段¶

    sounds 用于配置材料命中反馈。它包含两个子字段：

    字段 类型 默认值 说明
    hit_un_pen 音效事件 默认未击穿金属音效 未击穿时播放
    hit_pen 音效事件 默认击穿金属音效 击穿时播放

    它们不会改变伤害数值，但会显著影响玩家对材料“手感”的判断。玻璃、橡胶、木板、金属、复合装甲如果都沿用同一套音效，实战体验会非常难以区分。

    伤害修正器写法¶

    impact_modifiers、penetration_modifiers 和 damage_modifiers 三者共享同一种写法：都是一个按顺序执行的数组。每个条目包含：

    字段 类型 必需 说明
    operation 字符串 是 add 或 multiply
    value 浮点数 是 操作值
    condition 对象 是 生效条件

    最小示例：

    "damage_modifiers": [
  {
    "operation": "add",
    "value": -5.0,
    "condition": {
      "type": "damage_type",
      "id": "minecraft:fly_into_wall"
    }
  }
]

    这表示：若伤害类型是 minecraft:fly_into_wall，则先把输入值减去 5。多个条目会按顺序连续生效，因此它不是一组“互相独立的标签”，而是一条小型处理链。

    支持的条件类型¶

    当前实现支持以下条件：

    • always
    • damage_type
    • damage_tag
    • entity_type
    • entity_tag
    • and
    • or
    • not

    例如：

    {
  "operation": "multiply",
  "value": 0.5,
  "condition": {
    "type": "not",
    "condition": {
      "type": "damage_tag",
      "id": "minecraft:bypasses_armor"
    }
  }
}

    这表示：只要伤害不带 minecraft:bypasses_armor 这个标签，就把输入值乘以 0.5。

    编写建议¶

    写修正器时，建议优先遵循下面几条习惯：

    1. 先写“削减小额噪声伤害”的规则，再写更细的类型区分。
    2. 若需要“先减去固定值，再乘倍率”，就把 add 放在前面、multiply 放在后面。
    3. 如果一种材料只想轻微微调，优先在命中箱里用 overwrite 覆写；只有当多处都需要复用时，再新建独立材料文件。

    常见材料类型的调校思路¶

    装甲钢与结构钢¶

    这类材料通常应当具有：

    • 中低弹性
    • 中等或偏低滑移适应
    • 较高 rha
    • 较低 un_penetrate_damage_factor

    它们的核心定位通常是“厚了才耐打，斜了更耐打，但没穿透时不一定会留下明显残余伤害”。

    玻璃与脆性透明材料¶

    这类材料通常更适合：

    • 较高弹性或较脆的碰撞反馈
    • angle_effect = false 或较低抗穿预期
    • 较低 rha
    • 需要时用 un_penetrate_damage_factor 表现“没穿也会裂”

    同时最好配上独立的 hit_un_pen / hit_pen 音效。

    轮胎与橡胶材料¶

    这类材料的重点通常不在 rha，而在：

    • friction
    • slip_adaptation
    • slip_curve
    • rolling_friction
    • spinning_friction

    如果你在调车，轮胎材料往往比轮胎命中箱厚度更早决定玩家感受到的驾驶差异。

    检查清单¶

    完成材料定义后，可以按下面的清单自查：

    • [ ] 文件放在 materials/ 目录下，文件名和引用 ID 一致
    • [ ] $schema 路径正确，编辑器没有 schema 报错
    • [ ] 已明确区分这个材料主要服务于接地、装甲，还是两者兼顾
    • [ ] 若材料用于装甲命中箱，rha 与命中箱 thickness 的组合已经一起考虑
    • [ ] 若材料需要角度效应，angle_effect 保持为 true
    • [ ] 三类修正器中，已明确哪些规则是给冲击、哪些给穿深、哪些给最终伤害
    • [ ] 若希望未击穿也能造成残余损伤，已设置 un_penetrate_damage_factor
    • [ ] 若材料主要用于轮胎，已检查 friction、slip_adaptation 和 slip_curve
    • [ ] 命中音效已根据材料种类替换，而不是所有材料都沿用同一套金属声
