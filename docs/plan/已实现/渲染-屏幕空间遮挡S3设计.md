# Machine-Max 渲染 — 屏幕空间遮挡（S3）设计

> **状态**：生产表面项使用 `averagedLightVisibility` 的32点单边软深度响应平均，参数与公式见§2。§3记录供诊断对照的有限厚度硬命中算法；深度层级仅在F6截取时构建。GPU探针与十组保存输入验证见§8.9，运动镜头、多距离与Iris实机验收见§9。
>
> **本文自包含**：S2/S3的职责、软平均公式、硬命中参考、参数、失败模式与验证入口均在文内定义，不要求读过其他文档或本文的历史版本。

**术语**：`P` 为本像素的视空间受光点，`C` 为光心，`z = −viewPosition.z` 为正的前向深度（米），`raw` 为深度纹理值。深度标定满足 `raw = DepthB / z − DepthA`。

## 1. 职责与能力边界

| 项 | 回答的问题 | 检测 |
| --- | --- | --- |
| 表面项S3 | 可见几何应削弱多少表面光 | 沿P→C的屏幕线段平均32个单边软深度响应 |
| 星芒 S2 | 相机能否看见光心 | 在光心投影处采一次深度；按 `LightOcclusion` 逐盏选择 |
| 空气光晕 | 相机前可见空气段能贡献多少散射 | 沿相机视线积分，用本像素第一个表面距离 `tHit` 截断 |

相机看不见灯，不能据此关闭全部表面光。可见地面仍可能受到墙角、门缝或车体另一侧光源的照射。S3 只乘表面项：`E = color · intensity · window · orient · visible / max(d², d_min²)`。

S3的受光点范围由客户端`visual_effects.screen_space_light_shadow_range`控制，默认8m、可调0～64m；0关闭S3。范围内采样到光源的屏幕线段6%～88%区间，最后25%的受光距离平滑减弱阴影；达到范围上限的受光点跳过S3查询，表面光照、光晕和星芒照常计算。

输入是一张**单层相机深度图**。离屏几何、被前景完全覆盖的几何、没有写入快照的透明层均缺少证据。S3以车体连续挡住火光、少碎片与少异常投影为观感目标，接受柔和边界；它不承担完整几何阴影或严格点光源可见度的职责。单边响应没有物体背面信息，32点只能减弱离散轮廓，不能保证消除全部假遮挡。

## 2. 生产算法：32点柔和平均

3D线段投影到屏幕上是一条直线，`1/z`与`raw`沿屏幕参数仿射变化，米制深度不能直接线性插值。将P、C投影为像素坐标a、b后，`averagedLightVisibility`按下式计算：

```text
N = 32
t_i = mix(0.06, 0.88, (i + 0.5) / N), i = 0..31
uv_i = mix(a, b, t_i) / OutSize
rayRaw_i = mix(DepthB / zP - DepthA, DepthB / zC - DepthA, t_i)
rel_i = abs(rayRaw_i + DepthA)
perM_i = max(rel_i² / abs(DepthB), 1e-12)
diff_i = (sceneRaw_i - rayRaw_i) · sign(DepthB) - (0.08 · perM_i + 0.002 · rel_i)
response_i = clamp(diff_i / (0.25 · perM_i) + 0.5, 0, 1)
averageVisibility = clamp(1 - sum(response_i) / 32, 0, 1)
shadowWeight = 1 - smoothstep(0.75 · ShadowRange, ShadowRange, distance(P,C))
visible = mix(1, averageVisibility, shadowWeight)
```

`perM`是raw对米制深度的局部导数幅度；偏置对应0.08m加0.002倍射线前向深度，软过渡宽度对应0.25m。**0.25m不是有限背面厚度**，场景充分位于射线前方时响应饱和为1。标准深度与反向深度使用`sign(DepthB)`统一方向。深度纹理用NEAREST采样，不跨轮廓插值。

每个采样最多贡献1/32遮挡，遇到一个前景样本不会整条硬遮挡；连续充分遮挡可以让可见性降为0。越界样本响应为0、分母固定32；光心位于`zC≤NEAR_Z`时返回1。范围为0或受光距离达到范围上限时不调用采样函数。默认8m在0～6m完整应用平均遮挡，6～8m淡出，8m及以上零S3查询。

生产通路没有共享射线预算、不构建深度层级、不作首次命中早退。S4的邻域法线只在`NormalWeight>0`时读取；S2、空气光晕和星芒按各自规则计算。32点平均是屏幕空间柔和遮光近似，不能解释为真实光源面积采样所得的半影。

## 3. 诊断参考：有限厚度硬命中

以下函数供`CaptureTraversal=0/1/2`的硬命中对照及解析几何探针使用，不参与默认32点平均。屏幕倒数深度区间表达参考McGuire与Mara的《Efficient GPU Screen-Space Ray Tracing》；层级、插值确认与预算是本项目的诊断实现。

### 3.1 排除端点与裁剪

进入追踪前检查受光点到光源的距离。`ShadowRange≤0`或`distance(P,C)≥ShadowRange`时返回CLEAR，深度查询次数为0，也不消耗共享预算。范围选择不是把P→C截成受光点附近的一段。

1. 在 3D 空间沿 P→C 排除受光端 `OCCL_START_M` 米、光心端 `OCCL_END_M` 米。总线段短于两者之和时，待检查部分为空，返回 `CLEAR`。这些排除段是自遮挡策略，不算预算缺失。
2. 将待检查部分裁到 `z≥NEAR_Z`，再投影。两端均在近裁面外时返回 `UNKNOWN`。
3. 用 `clipRayAxis` 求屏幕线段与视口矩形的交集。像素坐标下界为 0，上界为 `OutSize−0.001`，防止 `floor(W)` 或 `floor(H)` 越界。
4. 视口裁剪同时插值两个端点的 `1/z`。近裁面或视口实际截去了线段时，标记证据不完整；可见部分若命中仍返回 `HIT`。

### 3.2 深度范围层级与自适应遍历

F6截取请求从同一张世界深度快照构建一次共享层级，供硬命中对照组使用。正常32点平均帧不创建或构建该层级。最细层每格覆盖2×2原始像素，尺寸向上补齐为2的幂；各高层由前一层2×2格归并，最后到1×1。归并纹理格式是RG32F，保存有效场景倒数深度的最小/最大值；第一分量的负号表示区域混有缺深度，(0,0)表示全无深度。补齐区域没有几何证据。奇数宽高最右/最下像素参与归并。

遍历维护屏幕线段进入当前格的参数及层级，求出退出这个格的参数。两参数给出整段的倒数深度范围。场景倒数深度范围为 `[sLo,sHi]` 时，对应有限厚度层的保守范围为：

```text
layerLo = sLo / (1 + biasRel + (biasM + T(1/sLo)) · sLo)
layerHi = sHi / (1 + biasRel + biasM · sHi)
```

`T`为§3.3的厚度函数。后界的倒数随`sceneInv`单调增长，因此用最小倒数深度`sLo`给出保守后界；诊断显式固定厚度时使用该固定值。粗层与叶节点使用同一厚度函数，避免过宽的粗层窗口增加细查成本。

射线区间与该范围不相交时，可跨过整个格；相交时只下钻，不能直接确认遮挡。下钻到原始像素才调用 `sampleLightRay`，用§3.3的精确有限厚度和接收平面规则确认。该像素没有命中便继续前进，并尝试升回粗层。由屏幕线段较大的轴长选择约32个初始粗格的尺寸；它不是32个孤立采样点，格内全部像素均被深度范围覆盖。

原始像素层枚举射线穿过的横竖网格边界，每格只检查进入/退出间的深度区间。格索引沿前进方向偏移0.001像素以消除边界浮点歧义；这个偏移不改变相交深度端点。点深度按像素内常量近似，候选命中按射线在格内的中点位置进行插值确认；亚像素细节与极短的擦边区间有像素级误差。

每个层级范围查询或原始像素深度查询均消耗一次预算。单条上限为 `min(OCCL_MAX_STEPS, 本像素剩余总预算)`，所有光源共用 `OCCL_PIXEL_STEPS`。候选命中的插值确认额外读取四个邻域深度，这四次读取不计入查询计数；它们只发生在点深度相交且接收平面排除未放行时。光源表按“来源优先级升序、投影半径降序、同键提交顺序”遍历，GPU数组与元数据一起排序。没有预算的灯返回UNKNOWN并放光。

粗格混有缺深度而被跨过时，路径保守记为缺证据；其中实际经过的细像素即使全有效，也可能在诊断中呈UNKNOWN。该标记只影响诊断，不凭粗格缺深度关闭光照；后续任意原始像素命中仍有权立即返回HIT。

层级由独立scratch颜色目标归并，逐层拷入最终mip；绘制附件和被采样纹理没有反馈环。归并shader的输入不是主目标深度，而是 `AFTER_LEVEL` 的世界深度快照。`ScreenSpaceDepthPyramid` 负责尺寸变化与资源释放，`PostProcessingGpuState` 隔离原生GL绘制并恢复引擎状态。3840×2019下层级为2048×1024的12层，层级与scratch合计约37.33 MiB；无光源的帧不构建。

### 3.3 有限厚度求交

```text
bias  = OCCL_BIAS_M + OCCL_BIAS_REL_Z · sceneZ
T(z)  = clamp(OCCL_THICKNESS_REL_Z · z, OCCL_THICKNESS_MIN_M, OCCL_THICKNESS_MAX_M)
front = sceneZ + bias
back  = front + T(sceneZ)
hit   = rayMax ≥ front && rayMin ≤ back
```

`bias`是表面到检测层之间的空隙，`T`是空隙之后的有限层厚，二者单位均为米。`z`是遮挡采样点的相机前向深度，不是受光点到光源的距离。默认5～10m取5cm、15m取7.5cm、30m及以上取15cm；`CaptureThickness>0`时诊断使用显式固定厚度。射线完全位于`back`后面时不命中；相同深度也不命中。不能将一个只有下界的深度阶跃称为有限厚度。

比较的是**整个像素格的射线区间**，不是某个孤立采样点，避免一步跨过薄层却没有点落进层内。

**连续表面确认**：点深度候选通过接收平面排除后，`filteredSceneInv`在射线格内中点手工读取四邻域，对`raw`作双线性插值，得到透视正确的倒数深度。若四邻域的倒数深度跨度超过中心点倒数深度的2%，使用点深度，避免把物体轮廓连成假表面。连续表面要求射线同时进入点深度与插值深度的有限层：前界取两者较远的深度加该深度的`bias`，后界取两者较近的深度加该深度的`bias`和点深度的`T`。这项确认减少像素常深度台阶的假相交；深度断层处保留点深度细节。全路径点采样诊断使用其采样位置，完整像素与层级遍历使用格内射线中点。

**接收平面排除**：四邻域重建的法线也用于 S3。光心位于接收面正侧时，候选场景点若落在 P 的局部平面空隙容差内，则该平面不提供遮挡证据。它排除掠射地面在像素常深度近似下的自交；离开该平面的墙体、车体和薄杆仍参与有限层检测。法线不可信时仅使用端点排除和深度空隙，不推断接收平面。`NormalWeight` 只改变 S4 的亮度响应；S3 开启时取四邻域不依赖该权重。

### 3.4 三态结果与光照合成

| 返回值 | 含义 | 表面项可见性 |
| --- | --- | --- |
| `RAY_HIT` | 检测到一次有限厚度相交 | `1−shadowWeight` |
| `RAY_CLEAR` | 排除端点后的待检查部分已完整检测，未命中 | 1 |
| `RAY_UNKNOWN` | 裁断、缺有效深度、越界或预算耗尽，且没有确定命中 | 1 |

遇到无有效深度的格继续检查其他格；后续命中有权返回 `HIT`。没有命中且曾缺证据，结束时返回 `UNKNOWN`。允许未知区域发光是接受漏光、减少误杀的策略，不能当成无遮挡证明。

点光源与不透明遮挡物的一次确认相交足以遮住该光。沿同一条射线累计命中次数不能代表光源的可见面积。表面阴影是二值近似；真实半影需要光源面积采样等独立设计。

范围权重为`shadowWeight=1−smoothstep(0.75·ShadowRange,ShadowRange,distance(P,C))`；范围为0时权重直接取0。默认8m在0～6m保留完整遮挡，6～8m平滑恢复表面光，8m及以上不查询。16m对应0～12m完整遮挡、12～16m淡出。渐变两端的一阶导为0；这是范围过渡，不代表面积光源半影，也不改变照明半径或强度。接收点在完整遮挡区时，HIT的可见性为0。

## 4. 参数与调试

生产参数固定为32点、屏幕参数区间[0.06,0.88]、0.08m+0.002z偏置和0.25m软过渡。客户端只提供§1的遮挡范围设置。以下`OCCL_*`常量仅控制§3的硬命中诊断参考：

| 常量 | 默认值 | 含义 |
| --- | --- | --- |
| `OCCL_MAX_STEPS` | 256 | 每条射线的层级/原始深度查询上限；0 为 S3 旁路 |
| `OCCL_PIXEL_STEPS` | 256 | 所有光源共用的每像素总查询上限 |
| `OCCL_START_M` | 0.05 m | 受光端排除长度 |
| `OCCL_END_M` | 0.15 m | 光心端排除长度，独立于 S2 的 `LightTol` |
| `OCCL_BIAS_M` | 0.03 m | 检测层前的固定空隙 |
| `OCCL_BIAS_REL_Z` | 0.001 m/m | 空隙随前向深度的增长量 |
| `OCCL_THICKNESS_REL_Z` | 0.005 | 厚度与场景前向深度的比例 |
| `OCCL_THICKNESS_MIN_M` | 0.05 m | 有限厚度下界 |
| `OCCL_THICKNESS_MAX_M` | 0.15 m | 有限厚度上界 |
| `OCCL_EDGE_REL_INV_Z` | 0.02 | 邻域倒数深度跨度的边缘保护阈值 |
| `OCCL_DEBUG` | 0 | 0 正常；1 三态；2 步数 |
| `ShadowRange` uniform | 8 m | 客户端性能选项`visual_effects.screen_space_light_shadow_range`，0～64m；0关闭S3 |

这些值是实现的标定起点，游戏内验收决定其观感是否合适。`OCCL_DEBUG=1` 在每像素首个实际求值的表面光源上输出：命中红、完整未命中绿、未知蓝。`=2` 输出 `已用查询/预算` 的灰度。没有符合条件的表面光源时保留正常输出。调试模式会替换光照画面，不能用于评估最终颜色。

深度纹理的 0/1 端点、近裁面以内的场景深度不提供有效几何。参数按米给，不能用 `raw` 的百分比代替：在 `raw≈1−0.05/z` 的投影中，1% 的 raw 差在 20 m 处就对应约 80 m 的局部深度跨度。

`01_current`和逐灯组的`_reasons.png`为参与光源最大加权遮挡量：黑=无遮挡，白=完全抑制表面光。`03_uniform64`、`05_full`、`08_hierarchy128`、`09_hierarchy_full`、法线厚度/光心端排除组的图显示硬命中原因，按全部参与表面光源聚合：橙为预算耗尽，紫为近裁面/视口裁剪，蓝为缺有效深度，青为全路径点采样未命中但点间空段未被检查，红为命中，绿为完整未命中，暗灰为未查询S3（无表面贡献、遮挡关闭或超范围）。多原因同时存在时依次优先显示橙、紫、蓝、青；某盏灯命中不清除其他灯的未知原因。

64/128 点方案是诊断候选：它以有限次数覆盖全程，不会把一条长射线只检查前 128 像素。点与点之间可能漏过薄物件或薄深度层，所以未命中返回 UNKNOWN，而不是完整无遮挡证明。该候选使用逐灯预算；与共享像素预算的成本和多灯公平性必须分别比较。

法线厚度候选每个原始像素另取四邻域重建遮挡面法线，步数图只计主深度查询，不含这四次额外邻域读取；该昂贵候选仅用于§3的完整像素硬命中参考。逐灯图包含非线性颜色合成，不能直接相加当作当前图。

`05_full` 检验的是遍历覆盖，有限层模型、接收平面排除和离屏限制均生效。`06` 能说明厚度敏感性，不能证明被填入的阴影物理正确。`07` 的可见表面后方没有厚度上界，因此容易填满实体投影，也会增加假遮挡和多重轮廓；默认32点使用相同的单边软响应、增加采样数以减小单个轮廓的离散贡献。

独立回放通过`tools/shader-diagnostics/diagnose.ps1 -Capture latest`执行；`-Shader current`使用工作区片元，`-Preset budget/range/thickness`生成相应对照。工具输出HTML分割对照、PNG拼图、差异热图、JSON和CSV；`-Pixel X,Y -Light N`检查指定光源的独立射线，详见工具README。

额外文件：`frame.json` 保存尺寸、两点标定、视图/投影矩阵、全部光源数组、各组参数及分块重放时间；`fragment.fsh`、`vertex.vsh`保存实际重放源码，`depth_reduce.fsh` 保存实际归并源码；`depth.f32be` 保存相机深度（大端 float32，OpenGL 自下而上行序）。PNG 已翻转为自上而下。格式1带有颜色、深度、三份源码的SHA-256及完整逐组uniform；独立回放验证文件尺寸、数组长度和已有校验值。截取结束核对原生 GL 状态，结果写入 `gl_state_restored`。

诊断在独立 RGBA8 目标重放，按 128×128 区域提交并逐行同步，不写主颜色或深度。原生 program、VAO、读/写 FBO、三个采样单元及进入时活动单元的纹理绑定、viewport、scissor、颜色掩码、深度掩码/函数、像素打包状态及相关开关均恢复；正常 PostChain 的 uniform 不参与诊断重放。没有引入世界 AABB、碰撞体查询或额外的车体几何。

## 5. 失败模式与回落

| 场景 | 行为 / 限制 |
| --- | --- |
| 灯心离屏 | 只读取屏内样本，屏外样本贡献0遮挡，分母固定32 |
| 灯心在相机后方或近裁面内 | 返回可见性1 |
| 遮挡物离屏、被前景完全覆盖 | 缺少几何证据，可能漏光 |
| 薄杆、栏杆 | 可能落在相邻样本之间；单个命中只贡献1/32 |
| 厚物件 | 前景可以连续削弱火光，但没有真实背面，可能出现过长的软投影 |
| 掠射地面 | 单边响应可能自遮挡，米制偏置和排除区间需实机评估 |
| 光源贴模型 | 光心侧12%的屏幕参数区间被排除，模型覆盖更长时可能误遮挡 |
| 镜头运动 | 固定32点没有随机噪声；物体轮廓和采样相位变化仍可能闪动，没有时域累积 |

## 6. 与其他效果的接线

`PostProcessingManager` 在 `AFTER_LEVEL` 先取世界深度快照，再提交光照 pass。S3 读取光照链自己的 `MCDepthSampler`，表面点与邻域法线也来自同一时刻的快照。所有快照都必须在链尾 `blit→main` 清主目标深度之前取得。

S3 在 `haloIn && hasSurface && d<R` 且朝向系数、强度均大于零时求值。表面光的距离窗、1/d²、有界合成以及 S4 法线响应各自保留其职责。`LightOcclusion` 只服务星芒的 S2；光晕由 `tHit` 截断。逐盏 `SCREEN_RAY` 与锥光编码是其他实施范围，提交处对未支持的编码返回 `UNSUPPORTED`。

## 7. 成本口径

每个有表面贡献且位于阴影范围内的光源至多读取32次深度，屏外样本不读；最多16灯，因此理论上限是每表面像素512次S3读取。没有按光源顺序分配的共享预算。S4在启用法线权重时每表面像素另需4次邻域深度读取；世界表面深度、S2及其他效果有各自成本。

正常渲染只使用世界深度快照，不构建层级。F6请求才创建并构建§3的诊断层级；诊断构建失败只取消截取，生产光照继续。层级及scratch在3840×2019下约37.33MiB，创建后由效果持有至重载或退出世界。32点不等于32/7倍总帧时间；灯的覆盖、纹理缓存与GPU分支会改变实际成本。§8.8的截图GPU计时只测诊断片元绘制，§8.1～8.7是明确算法基线的历史数据。

### 8.1 主轴DDA对照基线（2026-11-15）

### 8.8 新视角回归与柔和平均候选（2026-11-16）

20:23:44与20:24:04两组854×480、单灯、8m范围的保存输入暴露了§8.7薄层方案在炮口旁的块状异常投影。默认与完整像素参考之间，RGB差值超过2的像素分别为0与6；完整参考保留同样的大块异常，因此预算不是这两张异常的主要原因。8m是受光点到光源的筛选范围，范围内追踪完整P→C，不等于短程接触追踪。

本轮的观感目标是机体能连贯削弱火光、减少碎片与怪影，允许柔和过渡，不要求点光源的锐利硬边。§10描述的七点平均可按此目标作为视觉近似保留，不能只因其不等同严格可见度而淘汰。其米制算子在两组新输入上复算，与各自保存的`07_legacy7.png`均RGB逐位一致。

十组保存输入对比了原七点平均、七点最大响应/硬命中、64点硬命中、连续单边遍历、连续深度交点、短程接触、Bend判据的片元探针以及保留平均的候选。单改硬命中使分离轮廓加深；连续单边遍历能补覆盖，也会放大炮管的放射状假投影；短程单边与连续交点各有误挡或覆盖损失。它们没有作为生产替换。

## 10. 版本演进与问题基线

早期能产生多重阴影的 S3 将屏幕线段分为 8 段，在 7 个内部位置采样。场景比射线近时累加遮挡，再用 `visible=1−occ/7` 合成。其深度阶跃只有下界，没有厚度上界。同一遮挡物可在不同固定采样比例下映出多份缩放轮廓，每份单次命中只削弱 1/7 的光；提高分段数会把这些副本连成拖尾，单改成最大值会加深副本。

另一个独立错误是把偏置和过渡宽度写成 raw 的百分比。它让米制阈值随距离平方增大，几米外几乎没有遮挡。米制阈值恢复了遮挡强度。§3定义有限层和二值命中的诊断参考；§2和§8.8采用单边柔和平均作为生产视觉近似，分别评估连续挡光、分离轮廓和成本。

本节给出了两种问题的完整基线。§1–§7定义当前检测规则，§8–§9列出带明确算法/输入基线的验证与验收，不要求读者知道历史文件内容。

均匀点采样与旧算子是两个不同维度：64 点全程采样配合有限厚度和首次命中，不采用 `occ/K` 的沿线平均。固定点数仍可能漏采薄遮挡、随视角出现采样相位变化；这需要用 §4.1 的同帧图比较，不能从 7 点单边深度算子的失败推导出所有均匀采样方案均不可用。
