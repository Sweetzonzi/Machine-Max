# 载具系统-侵蚀贴图叠加渲染实施计划

> **状态**：计划中；方案已定，Blockbench 生成器和游戏接入待实现。适用：Minecraft NeoForge 1.21.1、Machine-Max 载具模型及内容包。
>
本文定义离线生成锈蚀叠加贴图的资源、状态与绘制契约。底色贴图保持原样；每个 `Part` 持有连续陈旧度，客户端将其映射到 0..16 显示档位，再为该 Part 的各个 `SubPart` 选用同一张二值 alpha 叠加贴图，在同一模型几何上额外绘制一次。Blockbench 预先读取底色像素并烘焙锈蚀混色；游戏使用 cutout 绘制，不依赖 Iris、光影包或自定义 shader。

## 1. 目标与决策

| 编号 | 决策 | 契约 |
|---|---|---|
| D1 | 锈蚀使用二值 alpha 预混色叠加贴图 | 原涂装不变；叠加层使用模型原 UV 和骨骼几何，alpha 仅为 0 或 255 |
| D2 | 连续值映射为 16 个叠加档 | `Part.staleness` 为 `[0,1]` 的连续 `float`；渲染档位为 `round(staleness × 16)`，0 不提交，1..16 每帧只选一张贴图 |
| D3 | 阶段图表达累计外观 | 第 N 阶段包含 1..N 阶段的全部锈蚀；不是差分贴图，不逐张叠画 |
| D4 | 状态按 `Part` 持有 | 服务端权威并随 Part 生命周期连续推进；一个 Part 下的所有 SubPart 共用同一档位 |
| D5 | Machine-Max 实现渲染接入 | 不增加 Spark-Core 公共 API、自定义 shader 或自定义 `RenderType` |
| D6 | 近景和远景一致 | 两条载具绘制路径共用阶段解析与骨骼过滤规则 |
| D7 | 锈层绘制在贴花上方 | 侵蚀命中处用预混色局部替换画面，表现贴花磨穿/锈蚀；未命中处透明，保留贴花 |
| D8 | Iris PBR 可选 | 基础二值 alpha RGBA 锈层不依赖 Iris；PBR 附图由 Iris/光影消费 |
| D9 | 首版范围限于颜色叠加 | 不含法线侵蚀、凹凸、穿孔、积雪或世界法线沉积 |
| D10 | 陈旧度与显示档位分离 | 存档保留连续值；客户端只在映射档位变化时收到渲染更新，避免每 tick 同步浮点变化 |

## 3. Blockbench 生成与资源契约

### 3.1 RGBA 侵蚀源图

插件以底色贴图的 UV 画布为侵蚀源图画布，输出同尺寸 RGBA 图。RGB 表示锈蚀外观，可绘制锈色色彩/纹理，也可由插件按材质参数程序化生成；A 表示开始显现的陈旧度阈值：`0.0` 表示不接收锈蚀，`(0,1]` 表示该像素开始出现锈蚀的陈旧度，值越低越早显现。透明孔洞、玻璃、橡胶及任何其他不应锈蚀区域由内容包作者设为 A=0。源图 A 是数值通道而非源图透明度；插件应提供 A 通道灰度预览，不能用常规透明预览误读侵蚀阈值。

RGBA 源图不是运行时着色器输入。插件结合源图、原底色像素、确定性噪声和锈斑参数，离线烘焙成 16 张阶段图。档位进度为 `stage / 16`；A 大于 0 且进度达到 A 经固定种子扰动后的阈值时，该像素 alpha 写为 255，否则写为 0。活动像素 RGB 按档位锈蚀强度将原底色与源图锈蚀 RGB 预混。导出 alpha 严格二值，不含半透明值。随机扰动使用可保存种子，参数相同则重复导出像素一致；各阶段沿用同一噪声场，保证侵蚀区域累计扩张。作者可预览无锈、低、中、高和 16 级结果。

每张阶段图独立表达该阶段完整锈蚀外观。alpha 只表示像素是否绘制，不承担混色强度；锈色与原底色的混合结果已经写入活动像素 RGB。源图 alpha 的阈值语义与导出图 alpha 的二值可见性语义不同。

### 3.2 文件命名与二值轮廓

阶段贴图与底色贴图位于相同资源命名空间和目录，在底色资源路径末尾追加 `_wear_` 与两位显示档位号：

```text
assets/machine_max/textures/vehicle/hull.png
assets/machine_max/textures/vehicle/hull_wear_01.png
...
assets/machine_max/textures/vehicle/hull_wear_16.png
```

`ResourceLocation` 不含 `.png` 扩展名。游戏以当前底色资源为 stem，追加 `_wear_01` 到 `_wear_16`；显示档位 0 不查找、不绘制纹理。`_wear_` 是 Machine-Max 的资源约定，Iris 不负责选择侵蚀阶段。

同一变体下每种底色贴图各自拥有对应阶段集，避免切换涂装后取到 UV、预混颜色或排除轮廓不匹配的锈层。不同涂装可共享生成参数，但必须基于各自底色像素烘焙并按各自底色路径导出。完全不提供阶段图表示该底色不支持侵蚀；一旦提供，1..16 必须齐全。

导出锈层使用 RGBA cutout：A=0 的像素露出下层，A=255 的像素绘制预混后的锈蚀颜色。插件按源图 A 和阶段生成二值 alpha，不从底色 alpha 自动推导接收范围；内容包作者须把底色透明孔洞和其他不锈蚀区域统一设为源图 A=0。透明轮廓不同的底色变体须分别提供相匹配的源图。首版不自动识别材质语义，舱罩、玻璃或镂空处是否接收锈蚀均由作者决定。

### 3.3 Iris PBR 附图

内容包可为阶段 albedo 提供 Iris 识别的同名 PBR 附图，例如阶段 stem 对应的法线图和材质图。Machine-Max 只绑定阶段 albedo，不解析或要求这些文件。无 Iris 或无兼容 shader pack 时，二值 alpha 锈层仍须正确显示。

插件可同步导出 PBR 附图；其通道编码、预览和 shader pack 表现单独验收。侵蚀等级命名与 Iris 的 PBR 附图后缀是两种独立约定。

## 4. 运行时状态与存档

每个 `AbstractPart` 增加服务端权威的 `staleness`，有限 `float` 范围 `[0,1]`；运行时随 Part 生命周期连续推进。渲染档位由 `renderStage = clamp(round(staleness × 16), 0, 16)` 派生：

- 服务端按生命周期连续更新并持有精确 `staleness`；所有属于该 Part 的 SubPart 共用派生档位，不维护彼此独立的陈旧度。
- setter 与存档解码拒绝 NaN / Infinity，并把有限值限制在 `[0,1]`；网络资源选择只接受 `0..16` 的派生档位，不能用状态拼任意资源路径。
- `staleness` 与耐久、毁坏状态、`textureName` 分开保存；具体锈蚀速率及伤害/环境修正规则由玩法配置另定，不从耐久比例自动推导。
- 完整状态写入 `AbstractPartData` 的公共字段，JSON 字段建议为 `staleness`，缺省 `0.0`；各具体 DTO 的固定序网络编码追加该字段。
- 完整恢复精确连续值；蓝图/骨架恢复从 `0.0` 开始，不把实例陈旧度复制到设计模板。
- 初始同步随 Part 完整状态发送；运行时只在派生显示档位变化时发送一次 Part 级增量，不按 SubPart 重复广播，也不逐 tick 发送浮点值；协议组版本随字段布局变更提升。

客户端渲染端从 Part 镜像取得档位，再对该 Part 的所有可见 SubPart 应用同一阶段贴图。后续受击、环境暴露、喷涂或维修可修改服务端连续值；各来源的幅度和规则需玩法定标。

渲染端以当前涂装的底色 `ResourceLocation` 和派生档位计算阶段纹理。阶段缺失时跳过锈层、不阻断底模，并在资源重载或首次诊断时按纹理集记录一次警告。`checkContent` 校验可选纹理集：全无表示未启用；任一存在则要求 1..16 齐全。

## 5. 渲染流程

### 5.1 近景与远景

近景在 `PartEntityRenderer` 的底色绘制之后，对所属 Part 派生档位大于 0 且资源集可用的 SubPart 再遍历同一组骨骼。使用 `RenderType.entityCutout(wearTexture)`、同一 `ModelInstance`、`ModelPose`、`PoseStack`、partial tick、根变换和现有几何辅助。一个 Part 内所有 SubPart 使用相同档位；锈层共享底模 UV、位置与动画，不创建贴花网格，也不改写模型、动画或底色资源。

远景在 `DistantVehicleRenderer#renderSubPart` 使用同一阶段解析、骨骼过滤和 cutout 锈层绘制。近远 LOD 交接需检查覆盖、闪烁、二值轮廓和 mipmap 下的细锈斑稳定性。

两条路径沿用当前 SubPart 的 packed light、overlay 和 RGB tint，使锈层服从世界光照与颜色 tint。发光眼睛/灯骨骼默认不接收锈层；组装线框路径跳过锈层。二值 alpha cutout 不提供半透明淡出语义；查看模式与销毁淡出的具体表现需单独验收，不将颜色 alpha 直接等同于平滑淡化。

### 5.2 贴花顺序与缓冲提交

贴花接入前，绘制顺序为底模 → 锈层。贴花接入后固定为：

```text
底模 -> 同一 SubPart 的贴花 -> 锈蚀阶段层
```

锈层保持深度测试，不关闭深度测试，也不改变深度写入以覆盖遮挡。alpha=0 时像素被丢弃，alpha=255 时写入烘焙的“原底色与锈蚀外观”混色，不执行半透明混合。锈层绘制在贴花之后，命中像素表现为锈斑磨穿/替换该处贴花画面，未命中区域仍显示贴花；它不修改贴花贴图、缓存或持久状态。Blockbench 预混只读取原底色，不包含运行时贴花；若要求锈蚀像素保留并混合动态贴花图案，需将贴花纳入烘焙或另设计运行时合成，本计划不承诺该效果。共享 `MultiBufferSource` 下仍须验证 cutout pass 与贴花 pass 的实际提交顺序。

## 6. 性能与兼容边界

- `renderStage == 0` 不遍历第二次模型、不请求侵蚀纹理、不提交额外顶点。
- 档位大于 0 时，该 SubPart 增加一次顶点提交和 cutout pass。阶段数不会变成绘制次数；每个可见 SubPart 每帧最多选择一张阶段图。二值 alpha 不需要透明物体排序，但贴花与锈层之间仍须保证 pass 提交顺序。
- 16 张 PNG 增加资源包体积和 GPU 纹理驻留。未压缩 RGBA 显存近似与 `宽 × 高 × 4 × 阶段数` 成正比，另计 mipmap 与驱动开销。按常见尺寸、唯一底色数及实测驻留策略记录预算，不能用 PNG 文件大小估算显存。
- 纹理切换按阶段资源发生；避免为每个骨骼创建新的 RenderType。若共享缓冲导致额外 flush 或顺序问题，以测量结果调整宿主提交批次。
- 标准实体 cutout 类型不增加 Iris 硬依赖。验收覆盖无 Iris、Iris + 兼容 shader pack、Sodium，以及近景实体和远景 `AFTER_LEVEL` 路径。
- PBR 附图不改变阶段选择、二值 alpha 轮廓或无 PBR 回退。不同 shader pack 对模组纹理、cutout PBR 和第二遍几何的响应需实测。
- 雪、泥、水渍等可另行评估相同的离线附层路径；本文只定义锈蚀，不引入通用材质层管理器。

## 7. 实施阶段

1. **P1 资源原型**：为一个代表性底色制作 RGBA 侵蚀源图，生成 1、8、16 档预混色 cutout 叠加图，核对 UV、阈值、透明孔洞/不锈蚀排除区、二值 alpha 和命名；随后生成完整 1..16 资源集。
2. **P2 近景绘制**：添加客户端档位解析和第二遍骨骼绘制；用测试夹具给 Part 写入 `0.0`、`1/16`、`0.5`、`1.0`，验证映射到 0/1/8/16 档以及姿态、骨骼分组、发光过滤、光照、毁坏淡出和查看 tint。
3. **P3 远景绘制**：接入 `DistantVehicleRenderer`，验证 LOD 交接和 `AFTER_LEVEL` 缓冲顺序。
4. **P4 状态同步与存档**：在 `AbstractPart` 加入服务端权威连续值及生命周期推进；初始同步和 `AbstractPartData` 持久化保存 float，运行时只在映射档位变化时增量同步；蓝图/骨架恢复 `0.0`；提升协议版本并覆盖编码往返。
5. **P5 Blockbench 导出**：加入 RGBA 源图编辑/导入、原底色采样、确定性噪声与阶段烘焙、预览、资源路径导出和可选 PBR 附图；内容检查报告缺失阶段组、尺寸不匹配及非二值输出 alpha。
6. **P6 兼容与预算**：完成 §8 验收，记录可见 SubPart 数、底模/锈层 draw 与 flush、阶段纹理驻留、GPU 时间和近远景结果，再确定默认尺寸及是否需要配置阶段数。

P4 实现生命周期连续推进的接线；基础速率、受击/环境修正、暂停条件及维修效果作为玩法参数另行定标。渲染开发夹具可直接设置 float，以覆盖档位边界。

## 8. 验收

### 8.1 资源与状态

- 源图 A=0 区域（包括透明孔洞及其他不锈蚀区域）各阶段保持 alpha=0；阈值较低区域先出现，陈旧度升高时活动区域只增不减；相同源图、底色、参数和种子重复导出逐像素一致。
- 阶段图尺寸与 UV 和底色一致；输出 alpha 仅为 0/255；活动像素 RGB 已按约定与原底色预混，排除区未产生锈层。
- 服务端 setter 与存档解码拒绝非有限值并限制到 `[0,1]`；旧存档缺 `staleness` 时恢复 `0.0`，完整存档往返保留连续值。
- 一个 Part 下所有 SubPart 始终使用同一档位；初始同步、档位变化增量同步与完整存档恢复一致；蓝图/骨架恢复为 `0.0`。
- 生命周期推进期间连续值可在相邻 tick 间变化，但客户端只在映射档位改变时收到增量；`0.0`、`1/16`、`0.5`、`1.0` 分别映射到 0、1、8、16 档。
- 完全缺少阶段集时底模正常且无逐帧日志；部分阶段集由 `checkContent` 指出底色资源与缺失等级。

### 8.2 画面与运行环境

- 显示档位 0、1、8、16 对照：0 档与未启用侵蚀时底模一致；其他档位只叠加一张对应资源，不替换 Part 选择的底色资源，未命中像素保持底色可见。
- 模型旋转、骨骼动画、子零件运动和近远 LOD 交接中锈层稳定贴合，无漏骨骼、错位、z-fighting、闪烁或透明孔洞填充。
- 世界亮度、受击/查看 RGB tint 同时作用时，锈层颜色与光照语义一致；发光骨骼不被污染；查看与销毁淡出的 cutout 表现单独记录并验收。
- 贴花接入后验证“底模 → 贴花 → 锈层”：锈层只在命中像素写入预混色，呈现贴花局部磨穿/锈蚀，未命中处保留贴花；不修改贴花状态；其他表面仍由深度测试遮挡。
- 在 vanilla、Sodium、Iris 无 shader pack、Iris + 至少一个目标 shader pack 下验证无崩溃；PBR 只在支持时增强材质，不影响无 PBR 回退。
- 对 0 档、单个/多个侵蚀 Part（覆盖单 SubPart 与多 SubPart 结构）、近景和远景记录稳态 GPU 时间及纹理显存；测量前不宣称无显著帧时影响。

## 9. 未定事项

- RGBA 源图的 RGB 与 A 通道编辑方式：Blockbench 画布内绘制、导入外部图，或两者兼有。
- 锈斑噪声、边缘形态、锈色色板与不同金属材质的默认参数，由首轮内容包原型定标。
- 二值 cutout 与查看/销毁淡出的组合表现需实测；若要求平滑整体淡出，须单独决定 cutout 专用方案或有限场景的半透明回退。
