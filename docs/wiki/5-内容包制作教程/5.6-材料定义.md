# 5.6 材料定义

材料定义 JSON 放置在 `materials/` 模块目录下，用于描述一个命中箱材料的基础物理属性。它不像零件定义那样直接决定模型、连接点或子系统，而是作为命中箱的"共用基线"，统一控制摩擦、滑移、弹性、方块破坏能力、装甲抗穿水平、全局减伤参数，以及受到伤害时如何把原始数值转换为穿深、冲击和最终伤害。

如果把命中箱理解为"几何形状 + 厚度 + 材料"的组合，那么几何形状决定碰撞体在哪里，厚度决定这一块有多厚，而材料决定"这块东西是什么做的"。这一点和第四章中的 `4.3 装甲与穿甲`、`4.4 伤害系统` 是直接对应的：`rha`、`decay_rha`、`decay_power`、`angle_effect`、`penetration_modifiers` 会影响能不能打穿以及装甲如何随耐久退化；`impact_modifiers`、`damage_modifiers`、`dmg_resist`、`dmg_mult` 和 `unpen_power` 会影响打上去以后具体怎么坏。

阅读本章前，建议先完成：

- [5.3 零件定义](5.3-零件定义.md) 中关于 `hit_boxes` 的部分；
- [4.3 装甲与穿甲](../4-物理与战斗机制/4.3-装甲与穿甲.md)；
- [4.4 伤害系统](../4-物理与战斗机制/4.4-伤害系统.md)。

## 文件位置

材料定义 JSON 放在内容包对应的命名空间目录下：

```text
spark_modules/
└── my_pack/
    └── my_mod/
        └── materials/
            ├── structural_steel.json
            ├── glass.json
            ├── normal_tire.json
            └── ceramic_armor.json
```

每个文件名（不含扩展名）即为该材料的内部 ID。模组加载时，以 `命名空间:文件名` 的格式注册材料，例如 `my_mod:structural_steel`。之后在命中箱定义中，通过 `material` 字段引用：

```json
"HullHitBox": {
  "type": "box",
  "material": "my_mod:structural_steel",
  "thickness": 6.0
}
```

与 `parts/`、`subsystems/` 等模块相同，`materials/` 下的 JSON 文件可以任意嵌套子文件夹来组织，但注册名仍然只取文件名本身，不包含路径。

## 材料与命中箱的关系

材料本身并不直接出现在世界里，它只会在命中箱引用后生效。对命中箱来说，材料定义主要承担三类职责：

1. 决定碰撞和接地表现，例如摩擦、滚动阻力、滑移曲线和弹性。
2. 决定装甲与穿深相关行为，例如 `rha`、角度效应和未击穿残余伤害。
3. 决定伤害如何被映射与修正，例如冲击修正、穿深修正和最终耐久伤害修正。

在第四章中，一个命中部位的基础装甲可近似写成

$$
A_{\text{base}} = t \cdot \text{RHA}
$$

其中 $t$ 是命中箱定义中的 `thickness`，`RHA` 则来自材料定义中的 `rha`。也就是说，材料定义提供的是“每单位厚度有多抗穿”，而不是整块装甲的最终强度。真正的防护水平仍然要和命中箱厚度一起看。

同样地，`4.4` 中提到的三类伤害入口

$$
I = f_{\text{impact}}(D), \qquad
P = f_{\text{pen}}(D), \qquad
D_{\text{final}} = f_{\text{damage}}(D)
$$

其中的 $f_{\text{impact}}$、$f_{\text{pen}}$ 和 $f_{\text{damage}}$，正是由材料中的 `impact_modifiers`、`penetration_modifiers` 和 `damage_modifiers` 提供。换句话说，材料不是在“加一点小修正”，而是在参与伤害系统的主干流程。

## JSON 结构

材料定义 JSON 采用三层分组结构，按职责划分为 `physics`（物理）、`armor`（装甲）和 `sounds`（音效）三个顶层对象：

```json
{
  "$schema": "...",
  "physics": { /* 摩擦、滑移、弹性等物理模拟参数 */ },
  "armor":   { /* 抗穿、减伤、修正器、耐久退化等装甲参数 */ },
  "sounds":  { /* 命中音效配置 */ }
}
```

### `physics` — 物理属性

字段名 | 类型 | 必需 | 默认值 | 说明
---|------|------|-------|----
`schema`                             | 字符串    | 否 | —                    | JSON Schema 引用路径
`physics`                            | 对象     | 否 | 默认物理属性             | 物理模拟参数组
`physics.friction`                   | 三维向量  | 否 | `[0.5, 0.5, 0.5]`     | 摩擦系数向量
`physics.slip_adaptation`           | 浮点数    | 否 | `0.5`                 | 滑移适应系数
`physics.slip_curve`                | 对象     | 否 | 默认滑移曲线              | 轮胎纵向与侧向滑移曲线
`physics.slip_curve.longitudinal`   | 对象     | 否 | 默认纵向曲线              | 纵向滑移率曲线参数
`physics.slip_curve.lateral`        | 对象     | 否 | 默认侧向曲线              | 侧向滑移角曲线参数
`physics.rolling_friction`          | 浮点数    | 否 | `0.2`                  | 滚动摩擦系数
`physics.spinning_friction`         | 浮点数    | 否 | `0.0`                  | 旋转摩擦系数
`physics.restitution`               | 浮点数    | 否 | `0.1`                  | 恢复系数（弹性）
`physics.block_damage_factor`       | 浮点数    | 否 | `1.0`                  | 方块破坏系数

### `armor` — 装甲属性

字段名 | 类型 | 必需 | 默认值 | 说明
---|------|------|-------|----
`armor`                              | 对象     | 否 | 默认装甲属性             | 装甲与减伤参数组
`armor.rha`                         | 浮点数    | 否 | `1.0`                  | 相对 RHA 抗穿系数（满耐久时）
`armor.decay_rha`                   | 浮点数    | 否 | `0.3`                  | 耐久归零时的 RHA 残余系数
`armor.decay_power`                 | 浮点数    | 否 | `1.5`                  | 装甲退化曲线指数（>1 则先硬后脆）
`armor.angle_effect`                | 布尔值    | 否 | `true`                 | 是否启用入射角等效厚度效应
`armor.unpen_power`                 | 浮点数    | 否 | `0.0`                  | 未击穿残余伤害指数
`armor.dmg_resist`                  | 浮点数    | 否 | `1.0`                  | 全局线性减伤值（满耐久时）
`armor.dmg_mult`                    | 浮点数    | 否 | `0.95`                 | 全局伤害乘数（满耐久时）
`armor.decay_dmg_resist`            | 浮点数    | 否 | `0.0`                  | 耐久归零时线性减伤的残余值
`armor.decay_dmg_mult`              | 浮点数    | 否 | `1.0`                  | 耐久归零时伤害乘数的残余值
`armor.impact_modifiers`            | 修改器数组  | 否 | 默认规则                | 把输入伤害映射为连接点冲击
`armor.penetration_modifiers`       | 修改器数组  | 否 | 默认规则                | 把输入伤害映射为穿深
`armor.damage_modifiers`            | 修改器数组  | 否 | 默认规则                | 条件化伤害修正（类型/实体特定调节）

### `sounds` — 音效属性

字段名 | 类型 | 必需 | 默认值 | 说明
---|------|------|-------|----
`sounds`                             | 对象     | 否 | 默认金属音效             | 材料命中音效组
`sounds.hit_un_pen`                 | 音效事件  | 否 | 默认未击穿金属音效         | 未击穿时播放
`sounds.hit_pen`                    | 音效事件  | 否 | 默认击穿金属音效           | 击穿时播放

> **字段概览**：从用途上看，`physics` 控制接地与碰撞行为，`armor` 控制装甲与伤害管线，`sounds` 控制命中反馈。所有字段均为可选，未填写时使用默认值。

## 摩擦与接地字段（physics）

### `friction`

`friction` 是一个三维向量，格式为：

```json
"friction": [x, y, z]
```

当前实现里，`x` 主要对应侧向摩擦，`y` 主要对应前向摩擦，`z` 没有明确实际效果，通常保持默认或与前两者接近即可。对于轮胎材料，这个字段直接参与了 `4.1` 中讲到的各向异性轮胎摩擦；对于普通车体材料，则更多表现为一般接触时的摩擦强弱。

因此：

- 希望轮胎直线抓地更强，可以优先提高前向分量；
- 希望轮胎转向支撑更强，可以提高侧向分量；
- 希望车体、滑撬、底板更容易滑移，则应适当降低对应分量。

### `slip_adaptation`

`slip_adaptation` 取值范围为 `0~1`，用于减弱湿滑和滑移对抓地力的削弱。在 `4.1` 中我们已经把它近似写成

$$
\text{effective_slip}=\text{slip}\cdot (1-\text{slip_adaptation})
$$

因此这个值越高，同一块湿滑地面给轮胎带来的附着损失就越小。越野胎和全地形胎通常应当给出更高的 `slip_adaptation`，而一些极端偏公路、高极限但怕湿地的轮胎，则可以把它压低。

### `slip_curve`

`slip_curve` 只在轮胎类材料上尤其重要，用于控制纵向滑移率和侧向滑移角变化时，摩擦缩放如何变化。它包含两组子对象：

- `longitudinal`
- `lateral`

#### `longitudinal`

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---:|---|
| `peak_slip_ratio` | 浮点数 | `0.20` | 达到峰值摩擦的纵向滑移率 |
| `base_scale` | 浮点数 | `1.0` | 滑移率为 0 时的摩擦缩放 |
| `peak_scale` | 浮点数 | `1.4` | 峰值滑移率处的摩擦缩放 |
| `kinetic_scale` | 浮点数 | `0.9` | 高滑移状态下的动摩擦平台 |

#### `lateral`

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---:|---|
| `peak_angle_deg` | 浮点数 | `12.0` | 峰值侧偏角（度） |
| `kinetic_angle_deg` | 浮点数 | `90.0` | 进入高侧偏角动摩擦平台的角度 |
| `base_scale` | 浮点数 | `1.0` | 侧偏角为 0 时的摩擦缩放 |
| `peak_scale` | 浮点数 | `1.2` | 峰值侧偏角处的摩擦缩放 |
| `kinetic_scale` | 浮点数 | `0.7` | 高侧偏角下的动摩擦平台 |

如果你希望一条轮胎更适合稳定抓地，应当让 `peak_scale` 较高、`kinetic_scale` 不至于掉得太多；如果希望它更容易进入漂移，则可以让峰值出现得更早，并让高侧偏角下的平台更低。

### `rolling_friction` 与 `spinning_friction`

`rolling_friction` 控制正常滚动时的阻力，直接影响滑行距离、巡航掉速和通过松软地面的吃力程度；`spinning_friction` 则更多影响绕接触法线方向扭动时的阻力，例如低速转向、原地扭身和轮胎拖拽。

它们不直接决定“能不能抓住地”，而是更多决定“抓住之后阻力有多大”。因此，公路胎、越野胎、金属履带、滑板、木质雪橇这类材料，就算基础摩擦差不多，这两个值也可以显著拉开操控手感。

### `restitution`

`restitution` 是恢复系数，范围 `0~1`。在碰撞章节中我们已经见过，它会直接参与碰撞能量与反弹计算。值越高，碰撞越偏向反弹；值越低，越偏向吸收能量。

对材料调校来说：

- 玻璃、硬橡胶、轮胎、冰面可以适当提高；
- 装甲钢、木材、纸、软塑料通常更适合较低值；
- 若某种材料碰撞后老是弹得过头，优先检查这个字段。

## 装甲与穿甲字段（armor）

### `armor.rha`

`rha` 是材料相对轧制均质装甲的抗穿系数。在 `4.3` 中，命中部位的基础装甲已经写成

$$
A_{\text{base}} = t \cdot \text{RHA}
$$

其中 `RHA` 就来自这里的 `rha`。默认值是 `1.0`，可以理解为“同厚度下，相当于标准 RHA 的抗穿水平”。

例如：

- `rha = 0.5`：同样厚度下只有一半的等效抗穿
- `rha = 1.0`：标准基准
- `rha = 1.5`：同样厚度下达到 1.5 倍等效抗穿

需要特别注意的是，`rha` 不是最终装甲值，它必须和命中箱的 `thickness` 一起看。调 `rha` 是在改材料质量，调 `thickness` 是在改几何厚度，两者职责不同。且 `rha` 仅代表满耐久时的 RHA 系数——当零件受到伤害、耐久下降后，实际的 RHA 系数会在 `rha` 和 `decay_rha` 之间按幂函数递减（详见下方 `decay_power`）。

### `armor.decay_rha`

`decay_rha` 是材料在耐久归零时的 RHA 系数。系统会在满耐久的 `rha` 和零耐久的 `decay_rha` 之间，根据当前耐久比例进行幂函数插值，从而让装甲防护随零件耐久连续退化。

默认值 `0.3` 表示零件完全损坏后仍保留满状态 30% 的抗穿能力。对于脆性材料（如陶瓷），可以设得更低；对于韧性材料（如结构钢），可以设得更高。

### `armor.decay_power`

`decay_power` 是装甲退化曲线的幂指数，**也是所有耐久相关衰减（RHA、线性减伤、伤害乘数）共享的退化指数**。实际 RHA 系数按以下公式计算：

$$
\text{RHA}_{\text{当前}} = \text{decay\_rha} + (\text{rha} - \text{decay\_rha}) \times \left(\frac{\text{当前耐久}}{\text{最大耐久}}\right)^{\text{decay\_power}}
$$

- `decay_power = 1.0`：线性退化，耐久掉一半，属性也掉一半
- `decay_power > 1.0`：前期退化慢、临近损坏时快速失效（脆性装甲的典型行为）
- `decay_power < 1.0`：前期退化快、后期趋缓（不常见，但可用于特殊材料）

默认值 `1.5` 提供了一个适中的"先硬后脆"体验：轻度损伤几乎不影响防护，但耐久过半后装甲会加速失效。

### `armor.angle_effect`

`angle_effect` 决定该材料是否启用入射角导致的等效厚度变化。若启用，则等效装甲近似为

$$
A_{\text{eq}}=\frac{A_{\text{base}}}{|\cos\theta|}
$$

这在 `4.3` 里已经详细讲过。对内容包作者来说，这个开关非常重要：

- 传统装甲板、斜面钢板通常应当保持 `true`
- 玻璃、布料、某些非典型防护层可以考虑设为 `false`

如果你发现某种材料做成斜面后防护提升不符合预期，首先就应检查这里。

### `armor.penetration_modifiers`

`penetration_modifiers` 用于把输入伤害映射成最终参与击穿判定的穿深。它正对应 `4.3` 中的

$$
P = f_{\text{pen}}(D)
$$

默认规则会让大多数不具备穿甲标签的伤害，在换算穿深时乘上一个较低系数。这样做的目的是避免原版普通伤害过于轻易地打穿重型命中箱。

这组修正器最适合用来表达：

- 某种材料特别怕爆炸冲击，但不怕普通小口径
- 某种材料对高能穿甲弹和钝击的抗性差异很大
- 某类命中来源应当几乎没有有效穿深

### `armor.unpen_power`

这个字段控制"没打穿时还有没有残余伤害"。在 `4.3` 中，未击穿残余伤害已经近似写成

$$
D_{\text{unpen}}
=
D_{\text{base}}
\left(\frac{P}{A_{\text{eq}}}\right)^k
$$

其中 $k$ 就是 `unpen_power`。

当它为 `0.0` 时，未击穿通常就没有额外残余伤害；当它大于 `0` 时，系统允许"差一点打穿"的攻击仍然对内部造成一定损伤。玻璃、脆性结构、冲击敏感设备和薄板后挂设备，都很适合利用这个字段来表现"没穿也会震坏"。

### `armor.dmg_resist` — 全局线性减伤

`dmg_resist` 是满耐久时材料的全局线性减伤值。在伤害管线的第二步，系统会从经过条件化修正的伤害值中**直接减去**当前的有效线性减伤值：

$$
D_{\text{after\_resist}} = \max(0,\; D_{\text{modifiers}} - R_{\text{effective}})
$$

其中 $D_{\text{modifiers}}$ 是经过 `damage_modifiers` 条件化修正后的伤害，$R_{\text{effective}}$ 是考虑耐久衰减后的有效线性减伤值（公式见下文）。默认值 `1.0` 表示满血时每击直接减免 1 点伤害。

### `armor.dmg_mult` — 全局伤害乘数

`dmg_mult` 是满耐久时材料的全局百分比减伤乘数。在伤害管线的第三步，系统将线性减伤后的结果乘以有效伤害乘数：

$$
D_{\text{final}} = D_{\text{after\_resist}} \times M_{\text{effective}}
$$

默认值 `0.95` 表示满血时承受 95% 伤害（即 5% 百分比减伤）。线性减伤和百分比乘算配合使用，可实现"削减免小额攻击、同时保留对大额伤害的防御梯度"的效果。

### `armor.decay_dmg_resist` 与 `armor.decay_dmg_mult` — 减伤的耐久衰减

线性减伤和伤害乘数同样随零件耐久连续退化，退化曲线与 RHA 共享同一个 `decay_power`：

$$
R_{\text{effective}} = \text{decay\_dmg\_resist} + (\text{dmg\_resist} - \text{decay\_dmg\_resist}) \times \left(\frac{\text{当前耐久}}{\text{最大耐久}}\right)^{\text{decay\_power}}
$$

$$
M_{\text{effective}} = \text{decay\_dmg\_mult} + (\text{dmg\_mult} - \text{decay\_dmg\_mult}) \times \left(\frac{\text{当前耐久}}{\text{最大耐久}}\right)^{\text{decay\_power}}
$$

默认值 `decay_dmg_resist = 0.0` 表示耐久归零时线性减伤完全失效；`decay_dmg_mult = 1.0` 表示耐久归零时百分比减伤完全消失（即承受全额伤害）。这意味着一块完好的材料有双重减伤保护，但随着耐久下降，两重保护都会逐渐消退。

> **设计思路**：`dmg_resist`/`dmg_mult` 与 `rha` 分别解决不同的问题。`rha` 决定"穿不穿"，`dmg_resist`/`dmg_mult` 决定"穿（或没穿）之后实际扣多少"。厚钢板可能 `rha` 很高但 `dmg_resist` 不高（穿透困难但穿透后伤害大）；陶瓷复合装甲可能 `rha` 适中但 `dmg_resist`/`dmg_mult` 很强（防穿透一般但吸收冲击极好）。

## 伤害修正字段（armor）

### `armor.impact_modifiers`

`impact_modifiers` 用于把输入伤害映射为连接点冲击，它对应 `4.4` 中的

$$
I = f_{\text{impact}}(D)
$$

这组修正器不会直接决定部件掉多少耐久，而是决定这次受击对连接点结构完整性有多大影响。因此它特别适合用来区分：

- “本体不一定很脆，但很容易把外挂件震掉”
- “本体容易掉血，但结构连接很稳”
- “对撞击特别敏感的脆性部件”

如果你发现某个材料总是“本体还没坏，东西先掉了一地”，优先检查的就应该是这里，而不是只盯着 `damage_modifiers`。

### `armor.damage_modifiers`

`damage_modifiers` 是**条件化伤害修正**——也即 `4.4` 完整体三步减伤管线的第一步：

$$
D_{\text{modifiers}} = f_{\text{damage}}(D)
$$

这一步只处理"按伤害类型、来源实体等条件"进行的针对性调整（例如忽略浆果丛、挂墙碰撞等小额噪声伤害）。它完成之后，才会依次进入 `dmg_resist`（线性减伤）和 `dmg_mult`（百分比乘算）。因此 `damage_modifiers` 不是最终伤害，而是进入全局减伤之前的前置调节层。

最常见的用途包括：

- 忽略过小的碰撞伤害
- 显著减弱某类环境伤害
- 让某种材料对特定伤害类型特别脆或特别硬

如果你做的是玻璃、纸板、橡胶护罩、木箱之类的材料，这一组字段往往会比 `rha` 更早决定它们的实际表现。

> **关于 `block_damage_factor`**：此字段已移至 `physics` 组下（即 `physics.block_damage_factor`），主要作用在 `4.5` 讨论过的方块碰撞与破坏流程中。撞角、推土板、金属履带、工程机具前端可以适当提高；轮胎、玻璃、脆性外壳应当降低。

## 命中音效字段（sounds）

`sounds` 用于配置材料命中反馈。它包含两个子字段：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `hit_un_pen` | 音效事件 | 默认未击穿金属音效 | 未击穿时播放 |
| `hit_pen` | 音效事件 | 默认击穿金属音效 | 击穿时播放 |

它们不会改变伤害数值，但会显著影响玩家对材料“手感”的判断。玻璃、橡胶、木板、金属、复合装甲如果都沿用同一套音效，实战体验会非常难以区分。

## 伤害修正器写法

`impact_modifiers`、`penetration_modifiers` 和 `damage_modifiers` 三者共享同一种写法：都是一个按顺序执行的数组。每个条目包含：

| 字段 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `operation` | 字符串 | 是 | `add` 或 `multiply` |
| `value` | 浮点数 | 是 | 操作值 |
| `condition` | 对象 | 是 | 生效条件 |

最小示例：

```json
"damage_modifiers": [
  {
    "operation": "add",
    "value": -5.0,
    "condition": {
      "type": "damage_type",
      "id": "minecraft:fly_into_wall"
    }
  }
]
```

这表示：若伤害类型是 `minecraft:fly_into_wall`，则先把输入值减去 `5`。多个条目会按顺序连续生效，因此它不是一组“互相独立的标签”，而是一条小型处理链。

### 支持的条件类型

当前实现支持以下条件：

- `always`
- `damage_type`
- `damage_tag`
- `entity_type`
- `entity_tag`
- `and`
- `or`
- `not`

例如：

```json
{
  "operation": "multiply",
  "value": 0.5,
  "condition": {
    "type": "not",
    "condition": {
      "type": "damage_tag",
      "id": "minecraft:bypasses_armor"
    }
  }
}
```

这表示：只要伤害**不**带 `minecraft:bypasses_armor` 这个标签，就把输入值乘以 `0.5`。

### 编写建议

写修正器时，建议优先遵循下面几条习惯：

1. 先写“削减小额噪声伤害”的规则，再写更细的类型区分。
2. 若需要“先减去固定值，再乘倍率”，就把 `add` 放在前面、`multiply` 放在后面。
3. 如果一种材料只想轻微微调，优先在命中箱里用 `overwrite` 覆写；只有当多处都需要复用时，再新建独立材料文件。

## 完整示例

下面给出一个适合教程使用的材料示例。它不是官方现成文件的逐字抄写，而是一个把轮胎、装甲和伤害修正思路揉在一起的教学样例：

```json
{
  "$schema": "../docs/zh_cn/schemas/base/material_attr.schema.json",
  "physics": {
    "friction": [0.55, 0.65, 0.5],
    "slip_adaptation": 0.35,
    "rolling_friction": 0.18,
    "spinning_friction": 0.02,
    "restitution": 0.08,
    "block_damage_factor": 0.9
  },
  "armor": {
    "rha": 1.25,
    "decay_rha": 0.35,
    "decay_power": 1.5,
    "angle_effect": true,
    "unpen_power": 0.2,
    "dmg_resist": 1.0,
    "dmg_mult": 0.95,
    "decay_dmg_resist": 0.0,
    "decay_dmg_mult": 1.0,
    "impact_modifiers": [
      {
        "operation": "multiply",
        "value": 0.7,
        "condition": { "type": "always" }
      }
    ],
    "penetration_modifiers": [
      {
        "operation": "multiply",
        "value": 0.5,
        "condition": {
          "type": "not",
          "condition": {
            "type": "damage_tag",
            "id": "minecraft:bypasses_armor"
          }
        }
      }
    ],
    "damage_modifiers": [
      {
        "operation": "add",
        "value": -6.0,
        "condition": {
          "type": "damage_type",
          "id": "minecraft:fly_into_wall"
        }
      },
      {
        "operation": "multiply",
        "value": 0.08,
        "condition": {
          "type": "damage_type",
          "id": "minecraft:sweet_berry_bush"
        }
      }
    ]
  },
  "sounds": {
    "hit_un_pen": {
      "sound_id": "machine_max:hit_box.hit.up_pen.metal",
      "range": 64
    },
    "hit_pen": {
      "sound_id": "machine_max:hit_box.hit.pen.metal",
      "range": 64
    }
  }
}
```

如果把这个材料配给一个厚度为 `6` 的命中箱，那么它的基础装甲可以粗略理解为

$$
A_{\text{base}} = 6 \times 1.25 = 7.5
$$

若命中箱还启用了角度效应，则最终参与比较的还会是

$$
A_{\text{eq}}=\frac{7.5}{|\cos\theta|}
$$

这正是材料定义和 `4.3`、`4.4` 直接接轨的地方。

## 常见材料类型的调校思路

### 装甲钢与结构钢

这类材料通常应当具有：

- 中低弹性
- 中等或偏低滑移适应
- 较高 `rha`
- 中等 `decay_rha`（损坏后仍有一定防护）
- `decay_power` 略高于 1.0（韧性材料退化温和）
- 较低 `unpen_power`

它们的核心定位通常是“厚了才耐打，斜了更耐打，耐久下降时防护不会突然崩溃”。

### 玻璃与脆性透明材料

这类材料通常更适合：

- 较高弹性或较脆的碰撞反馈
- `angle_effect = false` 或较低抗穿预期
- 较低 `rha`
- 较低 `decay_rha`（脆性材料一坏就几乎失效）
- 较高 `decay_power`（脆性材料退化剧烈）
- 需要时用 `unpen_power` 表现“没穿也会裂”

同时最好配上独立的 `hit_un_pen` / `hit_pen` 音效。

### 轮胎与橡胶材料

这类材料的重点通常不在 `rha`，而在：

- `friction`
- `slip_adaptation`
- `slip_curve`
- `rolling_friction`
- `spinning_friction`

如果你在调车，轮胎材料往往比轮胎命中箱厚度更早决定玩家感受到的驾驶差异。

## 检查清单

完成材料定义后，可以按下面的清单自查：

- [ ] 文件放在 `materials/` 目录下，文件名和引用 ID 一致
- [ ] `$schema` 路径正确，编辑器没有 schema 报错
- [ ] JSON 结构正确：`physics`/`armor`/`sounds` 三个顶层对象
- [ ] 已明确区分这个材料主要服务于接地（`physics`）、装甲（`armor`），还是两者兼顾
- [ ] 若材料用于装甲命中箱，`armor.rha`、`armor.decay_rha`、`armor.decay_power` 与命中箱 `thickness` 的组合已经一起考虑
- [ ] 若材料需要角度效应，`armor.angle_effect` 保持为 `true`
- [ ] 已检查 `armor.dmg_resist`、`armor.dmg_mult` 及它们的衰减值，确保减伤层级符合预期
- [ ] 三类修正器中，已明确哪些规则是给冲击（`armor.impact_modifiers`）、哪些给穿深（`armor.penetration_modifiers`）、哪些给条件化伤害修正（`armor.damage_modifiers`）
- [ ] 若希望未击穿也能造成残余损伤，已设置 `armor.unpen_power`
- [ ] 若材料主要用于轮胎，已检查 `physics.friction`、`physics.slip_adaptation` 和 `physics.slip_curve`
- [ ] 命中音效（`sounds.hit_un_pen` / `sounds.hit_pen`）已根据材料种类替换，而不是所有材料都沿用同一套金属声
