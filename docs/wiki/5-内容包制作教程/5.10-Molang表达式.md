# 5.10 Molang 表达式

Molang 是 Machine-Max 用于控制动画、HUD 显示和碰撞条件判断的表达式语言。Molang 基于 GraalVM JavaScript 引擎运行，语法与 JavaScript 表达式高度相似。本章面向 UGC 作者，介绍 Molang 在 Machine-Max 中的使用场景、可用绑定对象和常用写法。阅读本章前，建议先完成 [5.2 模型与动画](5.2-模型与动画.md) 中关于动画文件的基本概念。

## Machine-Max 中 Molang 的使用场景

Machine-Max 会在以下三种场景中解析和执行 Molang 表达式：

| 使用场景               | 出现位置                                                       | 用途                                       |
| ------------------ | ---------------------------------------------------------- | ---------------------------------------- |
| 零件动画               | `.animation.json` 中骨骼的 `rotation` / `position` / `scale` | 根据车辆或零件的实时状态驱动骨骼运动，如悬挂压缩、方向盘转动、指针偏转     |
| HUD 文本             | `huds/*.json` 中文本条目的 `molang_args` 字段                     | 将实时数据作为参数填充到 HUD 文本的翻译键占位符中，如速度数字、档位显示、油量百分比 |
| 碰撞箱条件表达式（`condition`） | 零件 JSON 中 `hit_boxes` 条目的 `condition` 字段                   | 控制碰撞箱动态生效或失效，如挡风玻璃被摧毁后方块不再阻挡子弹           |

> 动画中的 Molang 表达式以字符串形式直接写在 JSON 的骨骼变换值位置。HUD 和碰撞条件中的 Molang 表达式同样以字符串形式提供。所有场景下的表达式语法完全一致。

## 基本语法

Molang 表达式为单行 JavaScript 表达式，直接求值为一个数值或字符串。不需要分号结尾。

### 算术运算

```molang
1.0 + 2.0 * 3.0
(1.0 + 2.0) * 3.0
global.get('engine_speed') / 100
```

支持 `+` `-` `*` `/` 四则运算和括号分组。所有数值均为双精度浮点数。

### 比较与逻辑运算

```molang
speed > 0
durability <= 0
local.has_subsystem('engine') && local.subsystem_active('engine')
local.is_destroyed == 1.0
```

支持 `>` `<` `>=` `<=` `==` `!=` 比较运算符，以及 `&&`（逻辑与）、`||`（逻辑或）、`!`（逻辑非）。比较和逻辑运算的结果为 `1.0`（真）或 `0.0`（假）。

### 三元表达式（条件运算符）

```molang
// 基本形式：条件 ? 真值 : 假值
local.has_subsystem('engine') ? 1.0 : 0.0

// 嵌套使用
v.fuel_level > 50 ? 0.0 : (v.fuel_level > 10 ? 0.5 : 1.0)
```

三元表达式是 Molang 中最常用的条件分支手段。可以嵌套使用，但嵌套层级不宜过深以免影响可读性。

### 空值合并运算符（`??`）

```molang
// 当 get() 返回 null 时使用默认值
global.get('engine_speed') ?? 0.0

// 链式回退
global.get('engine_speed') ?? global.get('motor_speed') ?? 0.0
```

`??` 用于处理可能不存在或尚未就绪的信号值。当左侧值为 `null` 时，返回右侧的默认值。**强烈建议所有通过 `global.get()` 获取的数值信号都使用 `??` 指定默认值**，避免因信号通道尚未建立导致动画异常。

### 函数调用

```molang
math.sin(angle)
math.floor(value)
local.has_subsystem('subsystem.machine_max.engine')
global.get('steering')
```

函数调用的参数用逗号分隔。字符串参数需加单引号或双引号。

## 绑定对象一览

Machine-Max 在 Molang 执行环境中提供了以下绑定对象。这些对象是 UGC 作者获取载具和零件运行时数据的主要入口。

| 绑定名                    | 简写    | 来源              | 说明                                  |
| ---------------------- | ----- | --------------- | ----------------------------------- |
| `global`               | —     | Machine-Max 注册  | 装配体级别的属性和信号获取，可获取全装配体共享的信号值、耐久度、电力量    |
| `local`                | —     | Machine-Max 注册  | 当前零件（Part）级别的属性和方法，可获取连接器信息、子系统状态、零件耐久度   |
| `math`                 | —     | Spark-Core 内置   | 数学函数库，包括三角函数、取整函数、插值函数等            |
| `query` / `q`          | `q`   | Spark-Core 内置   | 通用查询函数，包括动画时间、实体速度、位置等信息            |
| `variable` / `v`       | `v`   | Spark-Core 内置   | 动画实例内共享的变量读写，保存跨帧状态                |

> `query` 与 `q`、`variable` 与 `v` 分别是同一对象的全称和简写。为简洁，官方内容包多数场景使用简写（如 `q.anim_time`）。

## global 对象

`global` 对象提供载具级别数据的访问入口。**`global` 绑定在零件动画上下文中也可用**——表达式会自动定位到当前零件所属的载具。

### global.get(key)

从载具的信号存储中获取指定通道的信号值。这是获取车辆运行数据的主要方法。

| 参数    | 类型   | 说明          |
| ----- | ---- | ----------- |
| `key` | 字符串  | 信号通道名称      |

**返回值**：信号通道的当前值（通常为 `double` 或字符串），通道不存在时返回 `null`。

**常用信号通道**：

| 通道名              | 类型                   | 说明                       |
| ---------------- | -------------------- | ------------------------ |
| `vehicle_speed`  | `double`（m/s）         | 载具当前合速度                  |
| `engine_speed`   | `double`（rad/s）       | 发动机输出轴当前转速               |
| `motor_speed`    | `double`（rad/s）       | 电动机输出轴当前转速               |
| `steering`       | `double`（-1.0 ~ 1.0） | 转向输入，负值为左转，正值为右转          |
| `throttle`       | `double`（0.0 ~ 1.0）  | 油门输入深度                    |
| `brake`          | `double`（0.0 ~ 1.0）  | 刹车输入深度                    |
| `gear`           | `double` 或字符串         | 当前档位（R = 倒档，N = 空档，数字 = 前进档） |
| `machine_hp`     | `double`              | 载具当前耐久度（生命值）              |
| `machine_max_hp` | `double`              | 载具最大耐久度                  |

> 上表列出的仅是常见通道。实际上信号系统是完全通用的——`SubsystemController` 中任何子系统写入的信号都可以通过 `global.get()` 获取。自定义子系统或 `ScriptableSubsystem` 可以写入任意自定义信号通道。

```molang
// 推荐写法：使用 ?? 确保默认值
global.get('vehicle_speed') ?? 0.0
global.get('steering') ?? 0.0
global.get('gear') ?? 'N'
```

### 载具属性

`global` 对象提供了以下可直接访问的属性：

| 属性               | 类型     | 说明         |
| ---------------- | ------ | ---------- |
| `durability`     | double | 载具当前总耐久度   |
| `max_durability` | double | 载具最大总耐久度   |
| `energy`         | double | 载具能量网当前总储能 |
| `max_energy`     | double | 载具能量网最大总储能 |

```molang
// 耐久度百分比
global.durability / global.max_durability

// 低能量警告
global.energy < global.max_energy * 0.1 ? 1.0 : 0.0
```

### global 对象在 HUD 上下文中的特殊性

当 Molang 表达式运行在 HUD 上下文（即 `huds/*.json` 的 `molang_args` 中）时，`global` 通过当前玩家所在的座椅定位到其坐入的载具。在其他上下文（零件动画）中，`global` 通过动画持有者（子零件）向上追溯到所属载具。

## local 对象

`local` 对象提供**当前子零件**级别的属性和方法访问。在动画上下文中，"当前子零件"指的是播放该动画的子零件实例；在 HUD 上下文中，"当前子零件"是玩家座椅所在的那个子零件。

### 零件属性

| 属性               | 类型     | 说明                        |
| ---------------- | ------ | ------------------------- |
| `durability`     | double | 当前子零件耐久度（若 `share_durability` 为 true 则为全零件共享池的值） |
| `max_durability` | double | 当前子零件最大耐久度                |
| `is_destroyed`   | double | 当前子零件是否已被摧毁（1.0 = 是, 0.0 = 否） |

```molang
// 零件耐久度百分比
local.durability / local.max_durability

// 摧毁后隐藏相关骨骼
local.is_destroyed == 1.0 ? 0.0 : 1.0
```

### local.get(channel)

从零件级别的信号存储中获取指定通道的信号值。与 `global.get()` 的区别在于此方法读取的是该零件本地缓存的变量。

| 参数      | 类型  | 说明     |
| ------- | --- | ------ |
| `channel` | 字符串 | 信号频道名称 |

### 连接器相关方法

#### local.has\_connector(connectorName)

检查指定名称的连接器是否存在且已连接到另一个零件。

```molang
// 检查前保险杠是否安装
local.has_connector('connector.machine_max.hull_front_bumper_left')
```

| 参数              | 类型  | 说明     |
| --------------- | --- | ------ |
| `connectorName` | 字符串 | 连接器名称  |

**返回值**：连接器存在且已对接时返回 `1.0`，否则返回 `0.0`。

#### local.connector\_offset(connectorName, axis)

获取指定连接器在指定轴向上的偏移量。在动画中常用于获取悬挂压缩量。

| 参数              | 类型   | 说明                  |
| --------------- | ---- | ------------------- |
| `connectorName` | 字符串  | 连接器名称               |
| `axis`          | 整数   | 坐标轴（0 = X, 1 = Y, 2 = Z） |

**返回值**：连接器当前偏移量（单位：米），连接器不存在时返回 `0.0`。

```molang
// 获取左前轮连接器的 Y 轴偏移（悬挂压缩高度）
local.connector_offset('connector.machine_max.left_front_wheel', 1)
```

#### local.connector\_rotation(connectorName, axis)

获取指定连接器在指定轴向上的旋转角度。

| 参数              | 类型   | 说明                  |
| --------------- | ---- | ------------------- |
| `connectorName` | 字符串  | 连接器名称               |
| `axis`          | 整数   | 旋转轴（0 = X, 1 = Y, 2 = Z） |

**返回值**：连接器当前旋转角度（单位：度），连接器不存在时返回 `0.0`。

### 子系统相关方法

#### local.has\_subsystem(subsystemName)

检查当前子零件是否挂载了指定名称的子系统。

| 参数              | 类型  | 说明     |
| --------------- | --- | ------ |
| `subsystemName` | 字符串 | 子系统名称  |

**返回值**：子系统存在时返回 `1.0`，否则返回 `0.0`。

#### local.subsystem\_durability(subsystemName)

获取指定子系统的当前耐久度。

| 参数              | 类型  | 说明     |
| --------------- | --- | ------ |
| `subsystemName` | 字符串 | 子系统名称  |

**返回值**：子系统当前耐久度（子系统不存在时返回 `0.0`）。

#### local.subsystem\_max\_durability(subsystemName)

获取指定子系统的最大耐久度。

#### local.subsystem\_active(subsystemName)

检查指定子系统是否处于激活状态。返回值：激活时为 `1.0`，否则为 `0.0`（子系统不存在时也为 `0.0`）。

#### local.subsystem\_destroyed(subsystemName)

检查指定子系统是否已被摧毁。返回值：已摧毁时为 `1.0`，否则为 `0.0`（子系统不存在时也为 `0.0`）。

```molang
// 发动机被摧毁时显示警告
local.has_subsystem('subsystem.machine_max.engine') && local.subsystem_destroyed('subsystem.machine_max.engine') ? 1.0 : 0.0

// 碰撞条件：玻璃被摧毁后方块失效（用于碰撞箱 condition 字段）
// 写法：!local.subsystem_destroyed('subsystem.machine_max.front_glass')
```

> 子系统名称的完整格式为 `subsystem.<命名空间>.<名称>`，例如 `subsystem.machine_max.engine`。这个名称与零件 JSON 中 `sub_parts` → `subsystems` 下挂载子系统时使用的键名一致。具体可参考 [5.5 子系统定义](5.5-子系统定义.md)。

## math 函数

`math` 对象提供了完整的数学函数库，由 Spark-Core 内置提供。所有三角函数均使用**度**（而非弧度）作为角度单位。

### 三角函数

| 函数               | 说明          | 示例                        |
| ---------------- | ----------- | ------------------------- |
| `math.sin(v)`    | 正弦（输入为度）    | `math.sin(90)` → `1.0`    |
| `math.cos(v)`    | 余弦          | `math.cos(0)` → `1.0`     |
| `math.tan(v)`    | 正切          | `math.tan(45)` → `1.0`    |
| `math.asin(v)`   | 反正弦（返回度）    | `math.asin(1.0)` → `90.0` |
| `math.acos(v)`   | 反余弦         | `math.acos(1.0)` → `0.0`  |
| `math.atan(v)`   | 反正切         | `math.atan(1.0)` → `45.0` |
| `math.atan2(y,x)` | 二维反正切（返回度）  | `math.atan2(1.0, 1.0)` → `45.0` |

### 指数与对数

| 函数                    | 说明          |
| --------------------- | ----------- |
| `math.exp(v)`         | e 的 v 次幂    |
| `math.log(v)`         | 自然对数        |
| `math.pow(base, exp)` | base 的 exp 次幂 |
| `math.sqrt(v)`        | 平方根         |

### 取整函数

| 函数             | 说明     | 示例                        |
| -------------- | ------ | ------------------------- |
| `math.floor(v)` | 向下取整   | `math.floor(3.7)` → `3.0` |
| `math.ceil(v)`  | 向上取整   | `math.ceil(3.2)` → `4.0`  |
| `math.round(v)` | 四舍五入取整 | `math.round(3.5)` → `4.0` |

### 其他函数

| 函数                       | 说明         |
| ------------------------ | ---------- |
| `math.abs(v)`            | 绝对值        |
| `math.mod(v1, v2)`       | 取余（v1 % v2）|
| `math.sign(v)`           | 符号（1.0 / -1.0 / 0.0） |
| `math.min(v1, v2)`       | 取较小值       |
| `math.max(v1, v2)`       | 取较大值       |
| `math.clamp(v, min, max)` | 限制到指定范围    |
| `math.lerp(start, end, alpha)` | 线性插值（alpha 范围 0~1） |

### 数学常量

| 常量       | 说明         | 近似值                  |
| -------- | ---------- | -------------------- |
| `math.pi` | 圆周率 π      | `3.141592653589793`  |

```molang
// 弧度/秒 → 转/分钟（RPM）
global.get('engine_speed') * 30 / math.pi

// 米/秒 → 公里/小时
global.get('vehicle_speed') * 3.6
```

## query 对象

`query` 对象（简写 `q`）由 Spark-Core 内置提供，包含动画时间、实体运动状态等通用查询。

### 属性

| 属性               | 类型     | 说明                       |
| ---------------- | ------ | ------------------------ |
| `anim_time`      | double | 当前动画实例的累计播放时间（秒）          |
| `ground_speed`   | double | 动画持有者实体的水平移动速度（基于 `deltaMovement` 计算） |
| `vertical_speed` | double | 动画持有者实体的垂直速度（落地时为 0.0）     |

### 方法

| 方法                            | 说明          |
| ----------------------------- | ----------- |
| `q.position()`                | 获取当前动画持有者的世界坐标位置（`double[]`，长度为 3） |
| `q.playSound(sound, source)`                 | 在动画持有者位置的上方 1 格处播放音效。`sound` 为音效 ID 字符串（如 `"minecraft:block.note_block.pling"`），`source` 为音效源分类（如 `"master"` / `"ambient"` / `"blocks"`） |
| `q.playSound(sound, source, volume, pitch)`  | 播放音效并指定音量（0~1）和音高（0.5~2.0）          |
| `q.playSound(pos, sound, source, volume, pitch)` | 在指定坐标播放音效，`pos` 为 `[x, y, z]` 形式的 `double[]` |
| `q.addParticle(particle, pos)`               | 在指定坐标生成粒子。`particle` 为粒子 ID 字符串，`pos` 为 `[x, y, z]` |
| `q.addParticle(particle, reader, pos)`       | 生成粒子并指定读取器（`reader` 为一个识别符字符串，用于粒子参数解析） |

> `query` 主要用于 `ScriptableSubsystem` 中的脚本动画，普通零件动画和 HUD 中较少使用。具体用例可参考官方内容包中的脚本子系统示例。

## variable 对象

`variable` 对象（简写 `v`）提供当前动画实例内可读写的变量存储。变量以名称索引，初始值为 `0.0`。

```molang
// 读取变量（不存在时自动初始化为 0.0）
v.my_counter

// 写入变量（通过赋值表达式，在 Molang 单行表达式中间接实现）
// 变量值在动画播放期间持续保持
```

`v.xxx` 常用于在动画帧之间传递状态，例如：
- 记录上一次 tick 的某个值以计算变化率
- 在动画中实现简单的状态机

> `variable` 变量的生命周期与动画实例绑定。动画停止或重新开始时，所有变量会重置。

## 实际使用案例

以下案例均来自 Machine-Max 官方内容包中的实际文件，可对照查看完整上下文。

### 案例 1：悬挂系统动画

**文件位置**：`machine_max/animations/part/ae86/ae86.animation.json`

通过 `local.connector_offset` 获取车轮连接器的 Y 轴位移，结合 `math.atan2` 计算悬挂连杆的实时角度，使用 `math.sqrt` / `math.pow` 计算连杆的长度变化：

```json
{
  "axisRightFront": {
    "rotation": [0, 0, "math.atan2(local.connector_offset('connector.machine_max.right_front_wheel', 1)*16, 20)"]
  },
  "rodLeftFront": {
    "rotation": ["-65.7725+math.atan2(20-local.connector_offset('connector.machine_max.left_front_wheel', 1)*16, 9)", 0, 0]
  },
  "rodLeftFrontInner": {
    "scale": [1, "math.sqrt(math.pow(20-local.connector_offset('connector.machine_max.left_front_wheel', 1)*16, 2)+81)/22", 1]
  }
}
```

关键点：
- `connector_offset(name, 1)` 获取 Y 轴偏移，乘以 16 将米转换为 Blockbench 单位。
- `atan2` 计算悬挂角度，基准值 `20` / `9` 为悬挂几何参数（bb 单位）。
- 连杆长度通过勾股定理计算（`sqrt((ΔY)² + (水平距)²)`），除以基准长度 `22` 实现归一化。

### 案例 2：HUD 转速表指针

**文件位置**：`machine_max/animations/hud/example_hud/example_hud.animation.json`

```json
{
  "Pointer": {
    "rotation": {
      "0.0": [0, 0, "240*(math.abs(global.get('engine_speed')??0)*30/math.pi)/9000"]
    }
  }
}
```

计算流程：
1. `global.get('engine_speed')??0` → 获取发动机转速（rad/s），缺失时取 0
2. `* 30 / math.pi` → rad/s 转 RPM（\( \text{RPM} = \omega \times 60 / (2\pi) = \omega \times 30 / \pi \)）
3. `/ 9000` → 以 9000 RPM 为满量程归一化到 0~1
4. `* 240` → 映射到 240° 的表盘范围

### 案例 3：HUD 数字速度显示

**文件位置**：`machine_max/huds/example_hud.json`

```json
"molang_args": [
  "math.floor((math.abs(global.get('vehicle_speed')??0.0)) * 3.6 / 100)",
  "math.floor(math.mod((math.abs(global.get('vehicle_speed')??0.0)) * 3.6, 100) / 10)",
  "math.floor(math.mod((math.abs(global.get('vehicle_speed')??0.0)) * 3.6, 10))"
]
```

三个 Molang 参数分别提取速度的百位、十位和个位数字，配合翻译键的 `%1$s%2$s%3$s` 占位符组合成完整的速度文本。`significand: 0` 字段确保数字不显示小数点。

### 案例 4：方向盘动画

**文件位置**：`machine_max/animations/part/ae86/ae86.animation.json`

```json
{
  "rot2": {
    "rotation": [0, 0, "global.get('steering')*225"]
  }
}
```

将转向输入 `steering`（-1.0 ~ 1.0）线性映射为方向盘旋转角度（±225°）。

### 案例 5：碰撞条件——玻璃被摧毁后失效

**使用位置**：零件 JSON 中 `hit_boxes` → `condition`

```json
"condition": "!local.subsystem_destroyed('subsystem.machine_max.front_glass')"
```

当挡风玻璃子系统未被摧毁时表达式为 `true`（碰撞箱生效），摧毁后表达式为 `false`（碰撞箱失效，攻击可穿透）。

## 常用模式与注意事项

### 信号安全访问

始终使用 `??` 为 `global.get()` 的结果提供默认值：

```molang
// 推荐
global.get('vehicle_speed') ?? 0.0

// 不推荐——通道不存在时返回 null，可能导致 NaN
global.get('vehicle_speed')
```

### 单位转换

Machine-Max 内部使用国际单位制，Molang 中涉及的值同样以此为基础。常见转换：

| 目标单位      | 转换公式                                   |
| --------- | -------------------------------------- |
| 速度（km/h）  | `speed_ms * 3.6`                       |
| 转速（RPM）   | `speed_rads * 30 / math.pi`            |
| 米 → bb 单位 | `meters * 16`                          |
| 角度 → 弧度   | `degrees * math.pi / 180`（通常用 math 函数自动完成） |

### 表达式的可读性

对于复杂表达式，建议提前在 JSON 注释或设计文档中记录每一步的计算逻辑，便于后期维护。

### 不能使用的 JavaScript 特性

Molang 引擎基于 GraalVM JavaScript，但仅支持**表达式**而非语句。以下写法**不可用**：

- 变量声明（`let`、`const`、`var`）
- 多行语句
- `if` / `for` / `while` 语句
- 函数定义

需要分支逻辑时使用三元表达式 `? :`，需要变量时使用 `v.xxx`。

### 常见信号通道参考速查

| 通道名              | 含义  | 来源子系统                    |
| ---------------- | --- | ------------------------ |
| `vehicle_speed`  | 载具速度（m/s） | `CarControllerSubsystem` / `MotorbikeControllerSubsystem` |
| `engine_speed`   | 发动机转速（rad/s） | `EngineSubsystem`        |
| `motor_speed`    | 电机转速（rad/s） | `MotorSubsystem`         |
| `steering`       | 转向输入 | `CarControllerSubsystem` |
| `throttle`       | 油门输入 | `CarControllerSubsystem` |
| `brake`          | 刹车输入 | `CarControllerSubsystem` |
| `gear`           | 档位   | `GearboxSubsystem`       |
| `handbrake`      | 手刹状态 | `CarControllerSubsystem` |

> 上表仅供参考。实际可用的信号通道取决于载具安装了哪些子系统。如需自定义信号通道，可使用 `ScriptableSubsystem` 编写 JavaScript 脚本向信号存储写入任意自定义键值。
