# 3.2 动力系统

动力系统是载具运动的力量来源。本章介绍三种提供或管理动力的子系统：发动机（内燃机）、电动机和电池。发动机和电动机负责将燃料或电力转化为机械能输出给传动系统，电池则作为电力储能的中间环节。在 3.1 中已说明，静态属性定义子系统的型号参数（额定功率、扭矩曲线、转动惯量等），动态属性定义该实例在零件内部与谁连接（`power_output` 目标等）。本章从行为层面说明动力系统的工作方式。

## 发动机（engine）

发动机是模拟内燃机行为的子系统。它接收油门信号（0\~1），按扭矩曲线输出机械能。发动机具有怠速维持逻辑——当转速低于怠速时自动补油以保证不熄火，当转速高于怠速时最低油门为零。

### 扭矩曲线

发动机的扭矩随转速变化，分为四个阶段：

1. **怠速区**（转速 0 → 怠速转速）：扭矩从零线性增长到 `idle_rpm_torque_ratio × 最大扭矩`。发动机刚启动时扭矩较弱。
2. **上升区**（怠速转速 → 峰值扭矩转速）：扭矩线性攀升至最大扭矩。这是发动机动力随转速提升而增强的区段。
3. **平台区**（峰值扭矩转速 → 红线转速）：扭矩从最大扭矩逐渐过渡到 `red_line_torque_ratio × 最大扭矩`。此阶段发动机保持高扭矩输出，是正常工作的核心区段。
4. **超速区**（超出红线转速）：扭矩指数级衰减。实际行驶中应保持转速在红线以下。

```text
扭矩
▲
│         ┌────────────────┐
│        ╱                  ╲
│       ╱                    ╲
│      ╱                      ╲
│     ╱                        ╲____
│    ╱
│   ╱
│──┘
└───┼────┼──────────┼─────────────┼──► 转速
   怠速  峰值扭矩    红线          超速
```

> 实际扭矩还会受当前耐久度影响：`扭矩系数 = 0.3 + 0.7 × √(当前耐久/最大耐久)`，这意味着耐久度降至 50% 时动力约下降至满状态的 79%。

### 油门控制

发动机油门由 `control_inputs` 指定的信号频道接收。油门值为 0\~1（与电动机不同，发动机不支持反向旋转），低于怠速时系统自动将最低油门维持在 `MIN_IDLE_THROTTLE` 以上以避免熄火。当油门信号频道无输入时，发动机进入怠速状态。

### 内部阻力

发动机运行时存在内部阻力矩，由 `damping_factors` 数组定义的各阶系数计算：`阻力矩 = Σ (系数ᵢ × |转速|ⁱ)`。转速越高阻力越大，最终净输出扭矩 = 油门开度 × 当前转速下的扭矩 − 阻力矩。调大 `damping_factors` 会降低发动机的最终输出，同时使空载转速更低。

### 四冲程与二冲程

`four_stroke` 字段控制发动机的工作循环。四冲程发动机（默认）每两转点火一次，二冲程每转点火一次。此参数主要影响合成音效的点火频率和音色，对动力计算本身无直接影响。`cylinder_count`（气缸数）同样只影响合成音效的排气脉冲特征。

### 信号输出

发动机输出的 `engine_speed` 信号（转速反馈）通过动态属性中的 `speed_outputs` 字段发送。控制器依靠此信号来调整换挡时机和动力分配，形成闭环控制。

## 电动机（motor）

电动机在功能上与发动机类似——都是将输入信号转化为机械能转速/扭矩输出——但在扭矩曲线和油门特性上有本质区别。

### 扭矩曲线

电动机的扭矩-转速曲线分为三段：

1. **恒扭矩区**（0 → 基速）：受电流限制，输出恒定的最大扭矩（`max_torque`）。电动机从零转速即可输出全扭矩，这使得电动机驱动的载具起步响应比内燃机更加直接。基速 = `max_power / max_torque`。
2. **功率衰减区**（基速 → 红线转速）：功率从峰值（`max_power`）线性衰减到 `red_line_power_ratio × max_power`，扭矩随之下降。衰减速率由 `red_line_power_ratio` 控制——该值越接近 1，高转速区的扭矩维持得越好，换挡效益越不明显；该值越小，功率衰减越陡峭，变速箱的作用空间越大。
3. **红线外**：扭矩指数级快速衰减，与发动机类似。

```text
扭矩
▲
│ ┌─────────────────────┐
│ │                      ╲
│ │ 恒扭矩区               ╲  功率衰减区
│ │                        ╲
│ │                         ╲____ 红线外
└─┼────────────────────────┼──► 转速
  基速                      红线
```

### 油门与反转

电动机的油门信号范围为 **−1\~1**，正值表示正向驱动，负值表示反向驱动。电动机不支持怠速概念——信号归零时输出扭矩立即归零。这使得电动机可以通过信号控制直接实现倒车，无需变速箱提供倒挡。

### 再生发电

当电动机被外力拖动（例如下坡时车轮反拖电机旋转），且当前转速方向与油门输入方向相反时，电机会进入发电模式，将机械能转换为电能回馈到电力网。发电效率由 `generator_efficiency` 字段控制（默认 0.85）。因此，配备电动机的载具在下坡或减速时不仅不消耗电力，还能为电池充能。

> 当前版本中，电力网的发电-用电生态尚未完全构建，电池和发电模式的实用场景有限。此功能为后续版本中混合动力和纯电载具预留。

### 内部阻力与耐久度衰减

电动机的内部阻力计算方式与发动机相同（通过 `damping_factors` 各阶系数），但默认值更低（`[10.0, 0.1, 0.00005]` vs 发动机的 `[20.0, 0.1, 0.00005]`），反映电机相比内燃机具有更低的内部机械摩擦。耐久度对扭矩的影响逻辑与发动机一致。

## 电池（battery）

电池是电力网的储能单元，实现充放电管理。它不直接产生或消耗机械能，而是接入全载具共享的电力总线（EnergyGrid），自动参与电力的供需平衡。

### 充放电逻辑

电池有三个核心参数：

- **`max_stored_energy`**：最大储能容量（J）。新创建的电池以 50% 电量启动。
- **`max_charge_rate`**：最大充电功率（W）。当电力网有剩余电能时，电池以不超过此值的速率吸收电能。
- **`max_discharge_rate`**：最大放电功率（W）。当电力网存在电力缺口时，电池以不超过此值的速率释放电能。

当电池电量低于 99% 时向电力网申报充电需求（需求值 = `max_charge_rate`），当电量大于 0 时向电力网申报放电能力（产能值 = `max_discharge_rate`）。电力网自动在全体电池、发电端和用电端之间完成功率平衡，内容包作者无需手动配置充放电路径。

### 当前适用场景

截至当前版本，模组内置的电力生产者（发电机）和电力消费者（用电器）尚未完全实现，电池与电力网的互动主要用于以下情况：

- 电动机的再生发电（下坡/减速时将机械能回充至电池）；
- 内容包作者通过自定义脚本子系统（`javascript` type）读取和操作电池电量。

在后续版本中，随着发电机（如内燃机驱动的交流发电机）和用电设备（如照明、雷达、主动防御系统）的加入，电池将承担更完整的储能与缓冲角色。

## 发动机与电动机的对比

| 特性     | 发动机（engine）   | 电动机（motor）   |
| ------ | ------------- | ------------ |
| 能量来源   | 燃料（当前版本简化）    | 电力网          |
| 油门范围   | 0\~1          | −1\~1（支持反向）  |
| 怠速     | 有怠速维持逻辑       | 无怠速，信号为零即停转  |
| 零转速扭矩  | 较弱（需从怠速爬升）    | 全扭矩输出        |
| 高转速特性  | 扭矩平台后衰减       | 功率线性衰减       |
| 发电能力   | 无             | 有（再生制动）      |
| 默认内部阻力 | 较高（20.0 常数项）  | 较低（10.0 常数项） |
| 合成音效类型 | 活塞发动机音效       | 无刷电机音效       |
| 冲程/极数  | 四冲程/二冲程 + 气缸数 | 无（统一的无刷电机模型） |

## 发动机与电动机的音效

发动机和电动机均采用多通道音频系统，在客户端根据实时转速动态合成或切换工况音效。基本原则是：

- 若内容包作者在 `working_sounds` 中提供了自定义音效映射（键为转速字符串、值为音效事件），模组使用这些映射进行插值播放。自定义音效的转速数量不限。
- 若未提供自定义音效，模组在游戏启动时自动合成一套从怠速/基速到红线转速两倍的工况音效序列。

播放时，根据当前实际转速选择最邻近的两个转速档位通道，以平方插值的方式混合音量（等功率思路），使转速变化时的声音过渡平滑自然。音高（`pitch`）随转速动态调整，使声效与发动机/电机的实际工况保持一致。

发动机的合成音效基于活塞发动机模型（考虑气缸数、冲程数、点火角度、排气歧管长度），电机的合成音效基于无刷直流电机模型（考虑极数、PWM 频率、红线转速、基频）。如需自定义音效，建议在测试阶段留空 `working_sounds` 使用合成音效确认参数无误后，再替换为自制的音频资源。

## 信号控制链

发动机和电动机的动力控制遵循以下流程：

1. 座舱（或脚本）发出 `move_control` 信号。
2. 车辆控制器接收 `move_control`，将其转换为 `engine_control` 信号（精确到 0\~100 的油门开度）。
3. 发动机/电动机接收 `engine_control`，将信号值除以 100 得到油门比例（0\~1 或 −1\~1），乘以当前转速下的扭矩计算输出扭矩。
4. 发动机/电动机将机械能通过 `power_output` 指定的目标传递给变速箱或其他动力消耗端。
5. 转速反馈（`engine_speed` / `motor_speed`）回传给控制器，用于换挡决策和牵引力控制。

> 座舱也可以跳过控制器直接将 `move_control` 信号发送给发动机——此时油门开度等同于玩家按 W 键的前进比例。这种方式适用于不需要自动换挡和转向辅助的简化载具。

## 车轮反馈对发动机/电动机转速的影响

当发动机或电动机通过机械能链路连接到轮胎时，轮胎的实际转速会通过机械能端口反馈回发动机/电动机。系统收集所有反馈转速后计算平均值，用于：

- **耦合扭矩补偿**：根据转速差（发动机转速 − 反馈转速）施加耦合扭矩，使发动机/电动机转速与负载转速趋向一致。
- **转速修正**：当有转速反馈时，发动机/电动机的实际转速会向外部平均转速靠拢（修正系数约 95% 内部 + 5% 外部），防止空载时转速无限升高。

当无转速反馈（即发动机/电动机未连接到任何机械能消费者）时，曲轴/转子仅受内部阻力减速，转速逐渐自然下降。
