履带包络线 · 纯 2D 验证

输入只有轮心与半径：每个圆盘采样 64 个边界点，做 monotone chain 凸包，再按弧长参数化。 这一页是凸包基线，同时跑解析解、独立几何性质与 300 组随机圆；抬轮/非凸包络见 non-convex.html。

场景矩阵

青色 = 圆盘包络 · 红色虚线 = 圆心凸包（错误做法） · 橙点 = 履带节位置

圆盘包络每个圆采样边界点后取凸包；圆盘本身仍是圆，折线是它的内接近似。
圆心凸包（负对照）只连轮心。半径不等时它会把大轮切掉；支撑函数测试必须抓住它。
原始采样点每个圆 64 个；凸包只保留真正支撑边界的点。
履带节按 s_i = (L·i/N + phase) mod L 等弧长放置，N 由 L / 0.2 m 推导。
