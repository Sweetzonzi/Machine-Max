# 标定卡片

日常标定直接把摘要、约束残差和结论输出到对话即可。需要长期回归基线、内容包交付说明或团队协作记录时，才保存这张卡片；它帮助下一轮改动对比参数漂移。

建议位置：`docs/标定/<载具>.md`。路径不作硬性要求，同一载具族放同一处即可。

## 算例：K17

数据取自 `Machine-Max_K17` 内容包，使用 `--occupant-mass 0` 的空车口径展示传动与阻力推导；日常单人报告默认另加 60 kg。整车按真车量纲标定：22 t、750 PS、8×8。

### 整车与发动机

| 项 | 值 |
|---|---|
| 整备质量 | 22 000 kg（车体 19 100 + 炮塔 2 500 + 8 × 50） |
| 驱动轮数 | 8 |
| 轮半径 | 0.84375 m（模型轮面球 27 单位 ÷ 32） |
| 怠速 / 最大扭矩 / 红线 | 250 / 2000 / 3000 rpm |
| 对应扭矩 | 2048 / 2560 / 1646 N·m |
| 曲线峰值功率 | 551.5 kW @ 2401 rpm |
| `max_power` 字段 | 551 620 W（750 PS），与曲线峰值偏差 0.02% |
| 比功率 | 25.1 kW/t |
| 扭矩储备系数 | 1.56 |
| `damping_factors` | `[3, 0.05, 0.00005]` |

功率峰落在 2401 rpm、红线前 20%，90% 功率带 1878–3000 rpm。峰值若落在红线上，最高档会先撞红线而留不出功率余量，换挡也总是掉出峰值——这条是「峰值必须早于红线」的由来。

### 档位

传动箱 `machine_max:k17_transmission` 的 8 个输出端减速比都是 1，`i_total` 由挡位传动比与 `final_ratio = 11` 相乘得到。

| 档 | 总传动比 | τ_w (N·m) | F_total (kN) | a (m/s²) | 绑定约束 |
|---|---|---|---|---|---|
| 1 | 51.81 | 16 579 | 157.2 | 7.15 | 动力源 |
| 2 | 34.54 | 11 053 | 104.8 | 4.76 | 动力源 |
| 3 | 23.10 | 7392 | 70.1 | 3.19 | 动力源 |
| 4 | 17.60 | 5632 | 53.4 | 2.43 | 动力源 |
| 5 | 14.19 | 4541 | 43.1 | 1.96 | 动力源 |
| 6 | 12.10 | 3872 | 36.7 | 1.67 | 动力源 |
| 7 | 9.54 | 3052 | 28.9 | 1.32 | 动力源 |

一档 `τ_w = 16 579` 低于 `max_drive_force = 17 000`，电机夹紧不生效；附着极限 227.0 kN 也高于需求 157.2 kN，附着不生效。所有档位都由动力源扭矩绑定，一档到七档的牵引力跨 5.4 倍。

级比：`1.500 / 1.495 / 1.312 / 1.240 / 1.173 / 1.269`。末端一级大于前一级，属于异常项；五档到六档的牵引力增益 17%，刚好在阈值上。

### 车轮与附着

| 项 | 值 |
|---|---|
| 轮端力矩上限 | 17 000 N·m/轮（一档 16 579，留 3% 余量） |
| 制动力 | 142.2 kN（附着封顶 227.0 kN） |
| 轮胎材质 | `off_road_tire`，`rolling_friction` 0.04 |
| 纵向摩擦（峰值） | `1.5 × 0.7 = 1.05` |
| 附着极限 | 227.0 kN（1.05 g） |

一档附着利用率 `157.2 / 227.0 = 0.69`：一档推力由动力源扭矩决定，八轮抓地还有三成没用上。制动侧 142.2 kN 同样低于附着极限，制动由制动力矩决定，减速度 `142.2 / 22 000 = 6.46 m/s²`（0.66 g）。驱动 7.15 与制动 6.46 的比值 1.11，略高于 0.7~1.0 的参考带。

### 阻力

| 项 | 值 |
|---|---|
| 前向 `Cd·A` | 21.94 m²（各子零件气动点求和，前向二阶系数均为默认 1.0） |
| 气动阻力 @ 97 km/h | 10.4 kN |
| 滚动阻力 | `C_rr = 0.04` × 22 000 kg × 9.81 = 8.63 kN，滑行减速 0.39 m/s² |
| 内阻 @ 2931 rpm | 26 N·m |

极速处总阻力 19.3 kN，气动 10.4 kN 占 54%，滚阻 8.63 kN 占 45%。

### 极速

```
v_red = 314.16 × 0.84375 / 9.54 = 27.8 m/s = 100.1 km/h
```

红线允许 100.1 km/h，功率平衡更早到：解 `F_res(v)·v = P_wheel(v)` 得 27.1 m/s = 97.7 km/h。该点发动机 2931 rpm、净扭矩约 593 N·m，七档净牵引力 19.1 kN 与气动加滚阻 19.1 kN 平衡。**瓶颈是功率，不是红线**；两者只差 2%，所以这台车的最高档已经贴着设计极速。

`Cd·A` 直接决定这一段：它是各子零件气动点的和，不含遮挡，真实值偏低一侧，实测极速会略高于 97.7 km/h。八轮车的大头是车壳与炮塔，改任何一个的前向二阶系数都会整体挪动极速。

### 反推：同一台车换目标

整车侧的量固定（22 t、八轮、`r = 0.84375 m`、`Cd·A = 21.94 m²`、`C_rr = 0.04`、红线 3000 rpm），改从需求出发：

| 需求 | 反推 | 结果 |
|---|---|---|
| 极速 60 km/h | `i_top = 314.16 × 0.84375 / (16.67 × 1.03)` | 15.44 |
| 只给极速 | `F_res = 4.02 + 8.63 + 0.43 = 13.08 kN`，`P ≥ 13.08 × 16.67 / 0.85` | 257 kW（约 350 马力） |
| 再加 500 PS @ 2600 rpm | `P_max = 367.8 kW`，`τ(2600 rpm) = 367 800 / 272.3` | 1351 N·m，`n_τ` 取 2600 |
| 校验功率下界 | 367.8 ≥ 257 | 可行，余量 1.4 倍 |

前两行说明只给极速时发生的事：传动比先被定死，功率只剩一个下界。把 500 PS 配到 22 t 上，余量比 12.9 t 时明显收窄——同一组功率在更重的车上不再是免费的。

同一组硬件下，`0→50 km/h` 的理论下限是 `M·v²/(2·P_wheel)`：`22 000 × 13.89² / (2 × 546 900) = 3.88 s`。这个数字不含换挡与阻力，实际时间要加 `换挡次数 × switch_time`，并按工程模型 §十在游戏内计时。

### 待办

- 一档附着利用率 0.69，传动比与扭矩都没用满抓地：要提爬坡与起步，加大一档总传动比或 `max_torque`，上限是 `μMg = 227.0 kN`。
- 六档与七档之间补一级，或把七档调整到 `0.72` 附近，使末端级比回到 1.2 上下。
- `Cd·A` 21.94 m² 不含遮挡；实测极速反算后替换。
- 抓地峰值与滚阻都待滑行、牵引两项实测复核，当前为按源码推导的暂定值。

> 本卡由 `scripts/calibrate.py --pack Machine-Max_K17 --occupant-mass 0` 生成基础数据，再人工补结论。

## 算例：单速车 mini_ev

同一个脚本用 `--occupant-mass 0` 跑 `Machine-Max_Civilian` 的 `mini_ev`，说明没有变速箱时总传动比只由传动箱决定；日常单人报告默认另加 60 kg。

| 项 | 值 |
|---|---|
| 整备质量 | 420 kg |
| 驱动轮数 | 2 / 4（前轮 `max_drive_force = 0`） |
| 轮半径 | 0.34531 m |
| 电机 | 20 kW，85 N·m，基速 2247 / 红线 10 000 rpm |
| 传动箱 | `machine_max:mini_ev_transmission`，两个后轮的 `power_outputs` 都是 8 |
| 总传动比 | 1（无变速箱）× 8 = 8.00 |
| 轮端 τ_w | `85 × 8 / 2 = 340 N·m`，低于 `max_drive_force = 1500`，夹紧不生效 |
| 前向 `Cd·A` | 2.37 m²（各子零件气动点求和） |
| 极速 | 81.1 km/h（4982 rpm，功率绑定），红线允许 162.7 km/h |

这张卡里唯一需要单独量出来的量是 `r_trans = 8`：它写在部件的 `subsystem_data` 里，与变速箱无关。若把 `r_trans` 当成 1，同一台车算出的极速只有 29.5 km/h 量级——轮端牵引力掉到八分之一，低速就被气动与滚阻卡住，看起来像「有功率却跑不动」。

## 验收清单

- [ ] 需求表填了哪些约束是给定的、哪些是按默认值补的，硬/软已标注
- [ ] 残差表没有负项；有负项时写明了放松的是哪条软约束
- [ ] `max_power` 与曲线峰值偏差 ≤ 1%，且曲线峰值落在 `max_torque_rpm` 与 `red_line_rpm` 之间
- [ ] 每个档位的绑定约束已标注，且不只写「发动机」
- [ ] 一档附着利用率在 0.85 ~ 0.95
- [ ] 相邻档总传动比差按参考阈值检查；实际换挡收益另用两档转速与曲线核算
- [ ] 驱动加速度与制动减速度都在 0.7 ~ 1.0 g 量级
- [ ] 极速由红线与功率平衡两条件分别求值，取较小者
- [ ] `Cd·A` 注明来源（包内系数还是 `--cd-area`），并给出数值
- [ ] 滚动阻力按 `C_rr × 法向载荷` 计算，`C_rr` 取自材质字段并乘了地面方块的倍数
- [ ] 内阻在红线转速下的数值已记录
- [ ] 传动三段（挡位传动比 × `final_ratio` × `power_outputs`）都记入传动表，乘积与 `i_total` 对得上
- [ ] 卡片中的质量、传动比、面积与 JSON 当前值一致
