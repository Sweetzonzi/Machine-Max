# 标定卡片

日常标定直接把摘要、约束残差和结论输出到对话即可。需要长期回归基线、内容包交付说明或团队协作记录时，才保存这张卡片；它帮助下一轮改动对比参数漂移。

建议位置：`docs/标定/<载具>.md`。路径不作硬性要求，同一载具族放同一处即可。

## 算例：K17

数据取自 `Machine-Max_K17` 内容包，使用 `--occupant-mass 0` 的空车口径展示传动与阻力推导；日常单人报告默认另加 60 kg。面积一项为按包围盒的估算，其余为参数直接求值。

### 整车与发动机

| 项 | 值 |
|---|---|
| 整备质量 | 12 900 kg（车体 10 000 + 炮塔 2 500 + 8 × 50） |
| 驱动轮数 | 8 |
| 轮半径 | 0.84375 m（模型轮面球 27 单位 ÷ 32） |
| 怠速 / 最大扭矩 / 红线 | 250 / 2000 / 3000 rpm |
| 对应扭矩 | 480 / 1200 / 960 N·m |
| 曲线峰值功率 | 301.6 kW @ 3000 rpm |
| `max_power` 字段 | 551 620 W（需 4390 rpm，曲线不可达，**不合规**） |
| 比功率 | 23.4 kW/t |
| 扭矩储备系数 | 1.25 |
| `damping_factors` | `[3, 0.05, 0.00005]` |

### 档位

传动箱 `machine_max:k17_transmission` 的 8 个输出端减速比都是 1，`i_total` 由挡位传动比与 `final_ratio = 11` 相乘得到。

| 档 | 总传动比 | τ_w (N·m) | F_total (kN) | a (m/s²) | 绑定约束 |
|---|---|---|---|---|---|
| 1 | 51.81 | 7772 | 73.7 | 5.71 | 发动机 |
| 2 | 34.54 | 5181 | 49.1 | 3.81 | 发动机 |
| 3 | 23.10 | 3465 | 32.9 | 2.55 | 发动机 |
| 4 | 17.60 | 2640 | 25.0 | 1.94 | 发动机 |
| 5 | 14.19 | 2128 | 20.2 | 1.56 | 发动机 |
| 6 | 12.10 | 1815 | 17.2 | 1.33 | 发动机 |
| 7 | 8.80 | 1320 | 12.5 | 0.97 | 发动机 |

一档 `τ_w = 7772` 低于 `max_drive_force = 8000`，**电机夹紧不生效**；附着极限 132.9 kN 也高于需求 73.7 kN，**附着不生效**。所有档位均由发动机扭矩绑定，一档到七档的牵引力跨 5.9 倍。

级比：`1.500 / 1.495 / 1.313 / 1.240 / 1.173 / 1.375`。末端一级大于前一级，属于异常项；五档到六档的牵引力增益为 17%，刚好在阈值上。

### 车轮与附着

| 项 | 值 |
|---|---|
| `max_drive_force` | 8000 N·m |
| `max_brake_force` | 9000 N·m |
| 制动力 | 85.3 kN（附着封顶 132.9 kN） |
| 轮胎材质 | `off_road_tire`，`rolling_friction` 0.04 |
| 纵向摩擦（峰值） | `1.5 × 0.7 = 1.05`，各向异性是否二次计入待实测 |
| 附着极限 | 132.9 kN（1.05 g） |

一档附着利用率 `73.7 / 132.9 = 0.55`，离 0.85 的下限还有距离：一档推力由发动机扭矩决定，抓地有一半没有用上。制动侧 85.3 kN 同样低于附着极限，制动由制动力矩决定，减速度 `85.3 / 12 900 = 6.61 m/s²`（0.67 g）。驱动 5.71 与制动 6.61 的比值 0.86，落在 0.7~1.0 内。

### 阻力

| 项 | 值 |
|---|---|
| 气动面积（脚本估算） | X/Y/Z = 28.9 / 42.5 / 13.4 m²（包围盒投影并集） |
| 气动阻力 @ 93 km/h | 5.8 kN |
| 滚动阻力 | `C_rr = 0.04` × 单轮载荷 15 818 N = 633 N/轮，八轮合计 5.06 kN，滑行减速 0.39 m/s² |
| 内阻 @ 2579 rpm | 20 N·m |

极速处总阻力 11.1 kN，气动 5.8 kN 占 52%，滚阻 5.06 kN 占 46%。

### 极速

```
v_red = 314.16 × 0.84375 / 8.8 = 30.1 m/s = 108.4 km/h
```

红线允许 108.4 km/h，功率平衡更早到：解 `F_res(v)·v = P_wheel(v)` 得 25.9 m/s = 93.2 km/h。该点发动机 2579 rpm、扭矩约 1061 N·m（净 1041，内阻已先扣），七档净牵引力 10.9 kN 与气动加滚阻 10.9 kN 平衡。**瓶颈是功率，不是红线。**

面积的不确定性直接决定这一段：逐零件 AABB 相加（不含遮挡）给出 21.9 m²，对应极速 79.0 km/h；轮廓并集 13.4 m² 给出 93.2 km/h。两者都不含遮挡折减，真实值偏向上限一侧，进游戏测一次即可收窄。

### 反推：同一台车换目标

整车侧的量固定（12.9 t、八轮、`r = 0.84375 m`、`A_z = 13.4 m²`、`C_rr = 0.04`、红线 3000 rpm），改从需求出发：

| 需求 | 反推 | 结果 |
|---|---|---|
| 极速 60 km/h | `i_top = 314.16 × 0.84375 / (16.67 × 1.03)` | 15.44 |
| 只给极速 | `F_res = 2.40 + 5.06 + 0.43 = 7.89 kN`，`P ≥ 7.89 × 16.67 / 0.85` | 155 kW（约 210 马力） |
| 再加 500 PS @ 2600 rpm | `P_max = 367.8 kW`，`τ(2600 rpm) = 367 800 / 272.3` | 1351 N·m，`n_τ` 取 2600 |
| 校验功率下界 | 367.8 ≥ 155 | 可行，余量 2.4 倍 |
| 想把这 500 PS 用满 | `v_power = 26.9 m/s`，`i_top = 265.1 / 26.9` | 9.84，极速约 97 km/h |

前两行说明只给极速时发生的事：传动比先被定死，功率只剩一个下界。后两行说明 500 PS 配 `i_top = 15.4` 的车极速只有 62 km/h，富余功率全部落到加速与爬坡上——与「额定功率写得很高却用不出来」是同一件事的两个方向，区别在于这次发生在设计阶段。

同一组硬件下，`0→50 km/h` 的理论下限是 `M·v²/(2·P_wheel)`：`12 900 × 13.89² / (2 × 312 600) = 3.98 s`。要 3 s 就得 415 kW 轮端功率，即 `P_max` 约 490 kW——这就是「加速指标反推功率」的用法。

### 待办

- 一档附着利用率 0.55，传动比与扭矩都用不满抓地：要提爬坡与起步，加大一档总传动比或 `max_torque`，上限是 `μMg = 132.9 kN`。
- `max_power` 取曲线峰值 301 620 W；当前 551 620 W 需要 4390 rpm，不可达。
- 六档与七档之间补一级，或把七档调整到 `0.72` 附近，使末端级比回到 1.2 上下。
- 气动面积按包围盒估算（13.4 m²），含遮挡与实测两项复核后替换。
- 抓地峰值与滚阻都待滑行、牵引两项实测复核，当前为按源码推导的暂定值。

> 本卡由 `scripts/calibrate.py --pack Machine-Max_K17` 生成基础数据，再人工补结论。

## 算例：单速车 mini_ev

同一个脚本用 `--occupant-mass 0` 跑 `Machine-Max_Civilian` 的 `mini_ev`，说明没有变速箱时总传动比只由传动箱决定；日常单人报告默认另加 60 kg。

| 项 | 值 |
|---|---|
| 整备质量 | 420 kg |
| 驱动轮数 | 2 / 4（前轮 `max_drive_force = 0`） |
| 轮半径 | 0.34531 m |
| 电机 | 20 kW，85 N·m，基速 2247 / 红线 10 000 rpm |
| 传动箱 | `machine_max:mini_ev_transmission`，两个后轮的 `power_outputs` 都是 8 |
| 总传动比 | 1（无变速箱）× 8 = 8.00 |
| 轮端 τ_w | `85 × 8 / 2 = 340 N·m`，低于 `max_drive_force = 1500`，夹紧不生效 |
| 极速 | 66.1 km/h（4064 rpm，功率绑定），红线允许 162.7 km/h |
| 估算极速（逐零件相加面积） | 58.2 km/h |

这张卡里唯一需要单独量出来的量是 `r_trans = 8`：它写在部件的 `subsystem_data` 里，与变速箱无关。若把 `r_trans` 当成 1，同一台车算出的极速是 29.5 km/h——轮端只剩 246 N 牵引力，8 m/s 处就被气动与滚阻卡住，看起来像「有功率却跑不动」。

## 验收清单

- [ ] 需求表填了哪些约束是给定的、哪些是按默认值补的，硬/软已标注
- [ ] 残差表没有负项；有负项时写明了放松的是哪条软约束
- [ ] `max_power` 与曲线峰值偏差 ≤ 1%，且曲线峰值落在 `max_torque_rpm` 与 `red_line_rpm` 之间
- [ ] 每个档位的绑定约束已标注，且不只写「发动机」
- [ ] 一档附着利用率在 0.85 ~ 0.95
- [ ] 相邻档总传动比差按参考阈值检查；实际换挡收益另用两档转速与曲线核算
- [ ] 驱动加速度与制动减速度都在 0.7 ~ 1.0 g 量级
- [ ] 极速由红线与功率平衡两条件分别求值，取较小者
- [ ] 气动面积注明来源（AABB 或显式），并给出三轴数值
- [ ] 滚动阻力按 `C_rr × 法向载荷` 计算，`C_rr` 取自材质字段并乘了地面方块的倍数
- [ ] 内阻在红线转速下的数值已记录
- [ ] 传动三段（挡位传动比 × `final_ratio` × `power_outputs`）都记入传动表，乘积与 `i_total` 对得上
- [ ] 卡片中的质量、传动比、面积与 JSON 当前值一致
