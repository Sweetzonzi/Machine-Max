# Machine-Max 动态 AUI HUD

帮助内容包作者交付绑定真实游戏数据的 HUD。本技能及随附参考可独立使用，不要求获取 Machine-Max 工程或安装开发工具。

## 使用前确认

确认目标内容包位置、游戏中实际使用的 Machine-Max/AUI 版本，以及要编辑的武器控制器、座位或瞄具。本文称武器控制器为 WC，部件为 Part；“宿主”指某个 HUD 所属的数据对象。

先读目标内容包已有的子系统配置、HUD 布局、样式和页面。使用本技能所述功能的运行环境需支持 machine_max:aui_hud、对应查询及 data-mm-* 标记；版本不支持时，应说明能力缺口并使用该版本支持的方案。不要发明查询名、填入模拟数字，或修改模组来掩盖不兼容。

技能内链接相对本技能目录；资源配置中的路径相对作者自己的内容包。

## 按任务读取

- 写表达式和动态列表：读 [绑定语法与查询词表](references/dialect.md)。
- 拆分组件、挂载资源、调整视角和验证：读 [组件设计与接入流程](references/workflow.md)。

## 方法

先整理“宿主 → 读数 → 查询 → 视角 → 显隐 → 组件”的小表。每项数据都要有真实来源；缺少查询的设计先明确限制，不用浏览器计时器或固定文字冒充游戏状态。

按信息需求选择粒度：

- 紧凑读数：名称、库存、简短准备状态。
- 逐管读数：每管弹药、准备进度与时间。
- 弹链面板：供弹选项、各链库存与选中状态，可与逐管列表并列。

作者决定名称、风格、信息粒度和位置。HTML/CSS 定义组件内部结构；布局定义屏幕投放和显隐；查询提供业务数据。主炮、同轴等命名不会触发自动分类、排序或避让。

## 必须保持的数据语义

- weapon.* 属于该 HUD 挂载的 WC；挂到座位上不会自动读取玩家当前武器。
- weapon.selected 表示观察者是否选中该 WC，不等于装填就绪或武器开关状态。
- 选中供弹、膛内弹和正在装填的来源分别表达。库存不含膛内弹；库存为零也可能有就绪管。
- 标签是显示文字，不是唯一身份；不能仅凭相同标签把进度归到某条弹链。
- 重复列表由绑定层展开，作者定义一项模板即可；下标不是稳定身份。
- data-mm-* 是 Machine-Max 提供的页面标记，浏览器自身不会执行这些绑定。

## 交付与验证

检查“页面 → 样式 → 布局 → 宿主视角字段”的整条资源链。使用真实游戏状态检查装填、切弹、控制组、视角、不同 GUI scale 和重载；浏览器预览只作视觉辅助。

交付时写清修改了哪个内容包、哪些宿主和视角、每种读数的口径、如何重载及已完成的验证。没有进入游戏就明确标注“尚未实机验收”。用户要求静态对照时，保留独立页面与布局，并说明切换哪些引用。
