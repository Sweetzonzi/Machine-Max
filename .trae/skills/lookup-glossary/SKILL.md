# 查找术语表

读取项目术语表文件（`docs/glossary.md`），快速将用户需求映射到项目中的核心概念，避免每次都需要深度检索整个代码库。

## 何时调用

- **每次用户提出需求时**：在开始处理任何复杂任务前，*必须*调用此技能
- **用户提到某个概念但未明确说明时**：快速查找该概念的定义
- **需要理解用户意图与项目概念的关系时**

## 操作步骤

### 1. 检查术语表是否存在

检查 `docs/glossary.md` 文件是否存在。

### 2. 读取术语表

读取 `docs/glossary.md` 的全部内容，熟悉项目中的核心概念。

### 3. 映射用户意图

将用户描述的需求与术语表中的概念进行匹配：

| 用户可能说 | 术语表中匹配的概念 |
|-----------|------------------|
| "添加一个新的交通工具类型" | `Vehicle`（载具）相关概念 |
| "修改碰撞检测逻辑" | `CollisionHandler`（碰撞处理）相关概念 |
| "实现数据同步功能" | `Network` / `DataSync` 相关概念 |

### 4. 利用匹配结果指导后续操作

- 如果术语表中有匹配的概念：**直接使用术语表中的关键类名**作为搜索关键词，定位到相关代码
- 如果术语表中没有匹配：执行常规的代码库搜索，并考虑是否需要更新术语表

### 5. 示例流程

```
用户："帮我给载具添加一个新部件"

→ 调用 lookup-glossary
→ 术语表中查到 Vehicle（载具）概念
→ 关键类: io.github.sweetzonzi.machine_max.common.vehicle.Vehicle
→ 直接导航到该类及其相关代码，无需全局搜索
```

### 注意事项

- **术语表是精简的**：只包含核心概念，不是完整的代码索引
- **如果术语表不存在**：建议用户先运行 `generate-glossary` 技能生成术语表
- **如果找不到匹配**：执行常规搜索，并考虑运行 `update-glossary` 来补充术语表
